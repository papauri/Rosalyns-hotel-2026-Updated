Admin reference

Who uses it

Where to find it

Signing in

Open /admin/login.php on the hotel's website address.

How to sign in

  1. Type your Username and Password. The eye button next to the password shows or hides what you type.
  2. Click Sign In. You go to the page you asked for, or to your home page.

How to reset a forgotten password

  1. On the sign-in page click Forgot Password?.
  2. Type your Email Address and click the button. You return to the sign-in page with "Password reset link sent to your email."
  3. Open the email and click the link. It expires in 1 hour.
  4. Choose a new password. Afterwards the sign-in page says "Password reset successfully. Please log in."

The link in the email uses the Website address set in Hotel Settings. At most 3 reset requests are allowed from one place every 15 minutes: "Too many reset requests from this location. Please try again in 15 minutes." New staff who were sent an invitation set their first password from the invitation link instead (see Staff & Access).

Lock-out

  • A wrong password shows "Invalid username or password. N attempt(s) remaining before lockout."
  • After 5 wrong passwords the account is locked for 15 minutes: "Account locked for 15 minutes due to too many failed attempts." If you try again during that time you see "Account temporarily locked due to too many failed attempts. Try again in N minute(s)."
  • If one location makes too many failed attempts you see "Too many login attempts from this location. Please try again in 15 minutes."
  • A correct sign-in clears the count.

Automatic sign-out

You are signed out after 8 hours without activity. The sign-in page then says "You were signed out after 8 hours without activity. Please sign in again." If your session expires on the sign-in page itself you see "Your session expired. Please try signing in again."

What the Search button finds

It searches the pages in your menu and the records you have access to: bookings (reference, guest name, email, phone), payments and receipt numbers, credit notes, quotations, conference and event enquiries, gym members, room types, rooms, menu items, stock, suppliers, contact messages, reviews, events, rate plans, staff, Hotel Settings sections and email templates. It only shows what you are allowed to see. Enter or a click opens the record. On list pages the row is scrolled to and highlighted.

It also searches these guides. Type a question ("how do I refund a payment") or paste an error message you see, and a Help & guides group lists the matching guide sections, problems and FAQs. They open in a new tab at the right place, with your words highlighted.

Searching the guides

  • Every guide page has a search box in its top bar. Press / to jump to it. It searches all the guides at once: every section, every "Problems and fixes" row and every FAQ.
  • The guides home page has a large search box with suggestions.
  • The FAQ page has the most common questions first, then every how-to and error message from all the guides. Type in its box to filter, or pick one guide.
  • When you open a result the page scrolls to the exact step or problem row and highlights your words. Click Clear highlights in the bar at the bottom to remove them, or Back to results to search again.

How to change your password

  1. Click the key button in the top bar.
  2. Fill in Current password, New password (at least 8 characters) and Confirm new password.
  3. Click Email Me a Verification Code. A 6-digit code is sent to the email address on your account. It expires in 10 minutes.
  4. Type the code in Verification code and click Confirm & Change Password. Use Cancel and start over if you need to start again.
  5. You see Password updated: "Your new password takes effect at your next sign-in."

The sidebar menu

  • The menu is split into groups: Front Desk, Conference & Events, Restaurant & Bar, Stock, Money, Gym, Website, Settings, Help and External. Click a group name to fold or open it. The number beside a group is how many items you can see in it.
  • You only see the items you have permission for. A group you have nothing in is hidden. Items that belong to a module that is switched off are hidden too (see Modules and business presets).
  • If you do not have the Dashboard permission, your menu only offers your station screens and the guides for them.
  • Help starts folded, unless the page you are on is inside it. The guides are there.
  • Search menus box: type part of a menu name to filter the list. If nothing matches you see "No matching menus."
  • Favorites: click the star at the right of any menu item to add it to the Favorites group at the top. Click the star again to remove it. When it is empty it says "Star menus you use often and they will stay here."
  • The double-arrow button at the top of the menu collapses it to a narrow strip. Your choice is remembered. On a tablet the menu starts collapsed.
  • POS Till, Kitchen, Bar, Coffee Bar and the guide links open in a new browser tab.
  • View Website (group External) opens the guest website.

System needs attention

A box that is normally hidden. It only appears for people with the System Logs permission, and only when something is wrong. The system checks every 5 minutes. It can list:

  • "The database is not responding."
  • "No backup has been taken yet." or "The last backup was N hours ago." (shown at 36 hours or more).
  • "Server disk space is low (N% free)." (10% or less).
  • "Unpaid booking holds have not been released for N hours." (25 hours or more; only when bookings are on).

The box has Backups and System Logs buttons.

Today's movements

The front desk worklist. Tabs, each with a count. Only the tabs for modules that are on appear:

  • Arrivals: today's arrivals still to come. Each row shows the guest, reference, room type, night count, room, status and either Due (an amount) or Paid. The Check in button works only when the booking is confirmed and paid; otherwise it says "Cannot check in: booking must be CONFIRMED and PAID."
  • Departures: guests due out today. The button is Settle & check out when they owe money (Owes ...) or Check out when they are settled. Both open the booking.
  • Events: today's conference events with times, room, number of guests and contact.
  • Room service: open room service orders, with how long each has waited (green under 15 minutes, amber from 15, red from 30) and a Take payment button.

Needs attention

A list of things waiting for someone, most urgent first (red before amber, then the biggest count). Each line shows a count and opens the right page. Lines with a zero count are hidden under "N queues clear". If there is nothing to do it says "All clear. Nothing is waiting on you." The lines that can appear:

  • Overdue arrivals (no-show?): arrival date passed, never checked in.
  • Bookings awaiting confirmation.
  • Departures with a balance: collect before they leave.
  • Refunds to approve.
  • Conference enquiries to answer.
  • Unread contact messages.
  • Reviews to moderate.
  • Event bookings pending.
  • Gym enquiries to answer and Gym memberships expiring (30d).
  • Rooms out of service and Housekeeping tasks due.
  • Room-service orders open and Room-service reminders due (rooms with no order served today).
  • Open tabs awaiting payment (called Orders awaiting payment when the restaurant page is off).
  • Expired stock batches and Items below minimum stock.

The other panels

  • Money: takings for the last 7 days as bars (click a bar to see that day), plus today's split between rooms and till sales, open tabs and Refunds pending. Day report opens End of Day.
  • Rooms: a ring chart of room status and a list of counts by status. Room board opens the room dashboard. Click a status to see those rooms.
  • Week ahead: arrivals and conference events for the next 7 days. Click a day to filter the list; Show all clears the filter.
  • Stock: Low, Expiring 7d and Expired counts, the lowest items and today's wastage. Manage opens the orders and stock page.

Backups

Admin menu → Settings → Backups (/admin/backup-management.php). Permission: Backup Management. Page title: Database Backup Management.

  • Four figures: Backup files on disk, Last successful backup, Last backup size and Backup health: Fresh (up to 25 hours), Getting old (up to 36 hours), Stale (older) or No backups.
  • Run Backup Now takes a backup (5 to 30 seconds; the page reloads). Success: "Backup completed via ...". Failure: "Backup failed (exit N, via ...): ...".
  • Available Backups lists the files, the newest marked Latest. Download and Restore are for users with the admin role only; everyone else sees Admin only.
  • Restore asks "This will OVERWRITE the live database with the selected backup. This cannot be undone." Click Yes, restore this backup or Cancel. Success: "Restore completed successfully via ...".
  • Backups run by themselves. The system takes one backup a day, the first time anyone opens the website or admin after 01:00. No cron job or server set-up is needed, and it still runs when the automated emails are switched off (the backup has its own switch under Automated Emails).
  • Warning if a backup is missed: people with the Hotel Settings permission see an orange dashboard banner, "No database backup in the last 36 hours", with a link to Admin → Automated Emails. That page shows Last database backup with its time and size, and an overdue tag when it is late.
  • The system keeps 14 daily, 8 weekly and 12 monthly backups; older ones are removed automatically. The page also shows a backup log and server checks.

A restore replaces everything in the live system with the older copy. Anything done since that backup is lost. Download a copy of a backup and keep it away from the server every week.

Modules

Admin menu → Settings → Modules. It switches areas such as Bookings, POS, Stock, Gym and Website on or off, and has one-click business presets. Read Modules and business presets before changing anything.

Cache

Admin menu → Settings → Cache (/admin/cache-management.php). Permission: Cache Management. The page title is Cache Management, with a pill Caching on or Caching off.

  • Individual cache controls: a table of cache types, each with a status and an enable or disable button. Message: "Cache 'x' enabled successfully!" or "... disabled successfully!"
  • Bulk cache clearing: tick the cache types and click Clear Selected Caches (asks "Are you sure you want to clear the selected caches?"). With none ticked: "Please select at least one cache type to clear."
  • Global cache control: Enable All Caching and Save Setting.
  • Quick actions: Purge SEO & Favicon clears the page caches and makes browsers fetch the icon and page details again. Use it after changing the logo, name or search-engine details.
  • PWA service worker: Bump SW Version Now forces every browser and installed app to fetch fresh copies. Use it after a significant update.
  • Scheduled cache clearing: clear caches automatically on a schedule.

Clearing the cache never deletes hotel data. The system rebuilds the copies as people use the website.

System Logs

Admin menu → Settings → System Logs (/admin/system-logs.php). Permission: System Logs. It is a read-only record for troubleshooting.

  • Cards for the last 24 hours: system events, admin activity, booking changes, POS orders, KDS/DS events, API calls, offline replays and errors.
  • Filters: Source, Level, Rows (20 to 500) and Auto-refresh 15s; click Apply, or Reset to clear.
  • Sections: System Event Stream, Booking Changes Audit, Recent Logins, Recent Admin Activity, POS Orders, Display Screens, Recent API Calls, Recent Offline Sync and File Log Tails.
  • Changes to settings, refunds, modules and sign-in attempts are recorded here with the person's name.

API Keys

Admin menu → Settings → API Keys (/admin/api-keys.php). Permission: API Keys. A key lets an approved outside website or app use the hotel's booking system. Page title: API Keys Management.

  1. Under the create form fill in Client Name, Client Email (both required), Client Website (optional) and Rate Limit Per Hour (default 100, at least 1).
  2. Tick the Permissions the client needs: read room names and prices, check availability, create bookings, read bookings, update bookings, cancel/delete bookings. Give only what is needed.
  3. Click Create API Key. The message "API key created successfully." shows the key. Copy it and send it to the client privately. The client sends it in the X-API-Key header.
  • In the API Keys table each key has Disable or Enable, Regenerate (asks "Regenerate API key for this client?"; the old key stops working) and Delete (asks "Delete API key for this client? This cannot be undone."). Reveal and copy buttons show the key.
  • The page also has a Meta Room/Price Template with a Copy button: current rooms and prices to paste into Facebook or Instagram replies.
  • Errors: "Client name and email are required." and "Enter a valid email address; name, email and website must each be under 255 characters."

Visitor Analytics

Admin menu → Website → Visitor Analytics (/admin/visitor-analytics.php). Permission: Visitor Analytics. It shows how guests use the website.

  • Filter by Period (Last 7 Days, Today, Last 30 Days, Custom Range) and Device (All Devices, Desktop, Mobile, Tablet, Bots); click Apply.
  • Panels include where traffic comes from, the booking conversion funnel, hourly traffic, visitor loyalty, entry and exit pages, most viewed rooms, countries, devices, browsers and referrers.
  • Cleanup older than (30, 60, 90, 180 or 365 days) and Cleanup delete old visitor records after you confirm "Cleanup old visitor analytics data now?". Result: "Visitor analytics cleaned successfully. Removed N visitor rows and N session rows older than N days." Only visitor statistics are removed.

Pages

Admin menu → Website → Pages (/admin/page-management.php). Permission: Page Management. Page title: Page Management: "Enable, disable, and reorder public website pages".

  • Each page has a button to disable or enable it, a button to show or hide it in the website menu, and an edit button for its title, icon and description.
  • Drag the rows into a new order, then click Save Order. Message: "Navigation order saved."
  • Switching a page: "Page "x" disabled." or "Page "x" enabled." The home page and the booking confirmation and review pages cannot be disabled: "This page is required by the system and cannot be disabled."
  • Add New Page: fill in the page key, title and file name (a root-level file such as spa.php), optionally an icon, description and heading, then Add Page. Message: "Page "x" added successfully." Errors include "Page key, title, and file path are required." "A page with the key "…" already exists.", "A page with the file path "…" already exists." and "A page called "…" already exists. Use a different name or edit the existing one."

Gallery

Admin menu → Website → Gallery (/admin/gallery-management.php). Permission: Gallery. Page title: Gallery Management.

  1. Click Add Gallery Item.
  2. Give it a title (required), a category (General, Exterior, Interior, Rooms, Facilities, Dining, Events or Spa & Wellness) and an image: upload a JPEG, PNG or WebP file, or paste an image address.
  3. Optionally add a video: paste a YouTube, Vimeo, Dailymotion or direct video address, or upload a video file.
  4. Save. You see "Gallery item added successfully!"
  • The buttons on the category bar (All and the categories) filter the list.
  • On each item: edit ("Gallery item updated successfully!"), switch active or hidden ("Gallery item status updated!") and Delete (asks "Delete gallery item?"; "Gallery item deleted successfully!"). A missing title gives "Title is required."

Media Portal

Admin menu → Website → Media Portal (/admin/media-management.php). Permission: Media Portal; needs the Website & CMS module. It is one list of every image and video the website uses: page banners (heroes), gallery photos, room pictures, conference and gym images. Each item is tagged to a page (for example index) and a section (for example hero), and saving it updates that place on the live website. Page banners set in Section Headers appear here automatically.

How to add an image or video

  1. Click Add Media. The Add New Media Item form opens.
  2. Type a Title (required, for example Homepage Hero Background). Choose the Page that shows it and the Section on that page, the Media Type (Image or Video) and a Display Order.
  3. Either Upload File — from your computer or paste an External URL. Images: JPG, PNG, WebP or GIF, at most 4 MB (under 1.5 MB is best for page speed). Videos: MP4, WebM, OGG or MOV, at most 100 MB.
  4. Fill in Alt Text (read out by screen readers and used by search engines) and, if you want, a Caption.
  5. To put the file straight onto a record, choose its Source Table, the Column to update and the Record ID. You then see "Media item created and pushed to … → …." Otherwise you see "Media item created." Click Add Item to save.
  • Filter by page or type: All Pages or one page, and All Types, Images or Videos. Click a picture to open it full size in a new tab.
  • Edit changes the title, description, alt text and placement, or replaces the file (Replace with new file or Or replace with URL), then Save Changes: "Media item updated." Delete is in the same Edit window and asks first: "Media item deleted." Each card shows its page, section, file and Display order, and the list shows a count such as "12 of 12 items".
  • Upload messages: "Uploaded file type is not allowed (JPG, PNG, WebP, GIF).", "Image is too large (…). Maximum is …", "File is too large (max 100 MB).", "Title is required."
  • To use a logo or picture elsewhere (for example the document logo in Hotel Settings), upload it here first, then paste its path.

Reviews

Admin menu → Website → Reviews (/admin/reviews.php). Permission: Reviews. Guests' reviews wait here until you publish them.

  • Summary cards: average rating and number published, Awaiting moderation, Published, no reply yet and Published 1–2★ reviews. Click one to filter.
  • Tabs: All, Pending, Published, Rejected. Filters: search, rating, Reply (Needs a reply or Replied), type and sort.
  • Buttons on a review: Approve & publish (pending) or Publish; Reject (pending) or Unpublish (published); Reply or Reply again; Delete. Deleting asks "Delete this review permanently?" and erases the review and the hotel's replies. Use Unpublish to hide a review without deleting it.
  • Replying: type the reply and click the send button. You see "Reply posted."
  • The page can also search for reviews elsewhere; Import as pending brings one in as a pending review for you to check and approve.

Contact Inquiries

Admin menu → Website → Contact Inquiries (/admin/contact-inquiries.php). Permission: Contact Inquiries. Messages sent from the website contact form.

  • Counts at the top: New / Unread, Read and more. Search with Search; Clear resets. Mark All Read (asks "Mark all new inquiries as read?") clears the unread count.
  • Each message has status buttons (new, read, replied, archived). Message: "Inquiry status updated to "x"."
  • Reply via Email opens a window: give a subject (under 255 characters) and message (under 5,000), then click Send Reply. Success: "Reply sent to <guest> from <hotel address>."
  • Delete asks "Delete this inquiry? This cannot be undone." and then says "Inquiry deleted."
  • If the hotel's sender address is missing, the reply cannot be sent: "Hotel sender email is not configured. Set the Email From Address in email settings first." Fix it in Hotel Settings → Email Configuration.

Section Headers

Admin menu → Website → Section Headers (/admin/section-headers-management.php). Permission: Section Headers. Page title: Section Headers Management. It edits the headings on the guest website. Two tabs:

  • Page Hero Text: the big heading and text at the top of each page (Save Hero Text), and Add Hero for New Page (Create Hero Entry). Saving: "Page hero text updated successfully!"
  • Section Headers: the headings above sections within pages. Saving: "Section header updated successfully!" You can switch a header on or off ("Section header status updated!") and reset one to its default ("Section header reset to default successfully!"). A reset-all option restores every header to factory defaults: "All section headers have been reset to factory defaults!"

Footer

Admin menu → Website → Footer (/admin/footer-management.php). Permission: Footer Management. Page title: Footer Management. This is also where the hotel's name, logo, main phone, email, address, working hours and social links are set.

  • Footer Link Columns and Add New Footer Link: link columns in the website footer. Messages: "Footer link added.", "Footer link updated.", "Footer link deleted.", "Footer link visibility toggled."
  • Policies & Modal Content and Add New Policy: policy texts shown in pop-ups. Messages like "Policy "x" added." and "Policy deleted."
  • The settings form has four parts: Site Identity (Site Name, Tagline, Logo), Contact Information (Phone Number, Email Address, Address, Working Hours), Social Media Links (Facebook URL, Instagram URL, Twitter / X URL, LinkedIn URL) and Copyright & Credits (Copyright Text, Design Credit / Tagline).
  • Click Save Site & Footer Settings. You see "Site and footer settings saved." The site name cannot be empty ("Site name is required."), the email must be valid ("Invalid email address.") and social links must start with http:// or https:// ("Invalid URL in social media fields.").
  • The Logo box takes a file path or web address. Upload the file in Media Portal first, then paste its path.

Rules the system enforces

  • You only see menu items you have permission for, and only for modules that are on.
  • You are signed out after 8 hours without activity. 5 wrong passwords lock an account for 15 minutes.
  • Changing your password needs a code sent to your email.
  • Only the admin role can download or restore backups.
  • Changes to settings, modules, refunds and sign-in attempts are written to System Logs with the person's name.

Duplicates and required fields

Every add and edit form checks what you type before saving. Extra spaces are removed, and names are compared without caring about capital letters or doubled spaces, so "Deluxe  room" counts as the same name as "Deluxe Room".

If you try to add something that already exists, nothing is saved and you see a message such as "A supplier called "…" already exists. Use a different name or edit the existing one." Edit the existing record instead.

What you addCounts as a duplicate when…
Staff memberThe username or the email address is already used (any capitals).
Room typeSame name.
Individual roomSame room number. Joined rooms: same name, or the same two rooms already joined.
Rate plan, room package, deal, conference room, gym package, supplier, stock item, API clientSame name.
Menu itemSame name in the same category of the same menu (food or drinks).
RecipeA menu item already has a recipe, or the same ingredient is listed twice.
EventSame title on the same date.
Gym classSame title on the same days at the same time.
Gym memberThe email address or phone number already belongs to a member (the message names them).
Housekeeping taskAn open task of the same type for the same room on the same date.
Maintenance requestAn open request with the same title for the same room.
Footer link, policy, page, hero, gallery itemSame link text in the same column; same policy slug; same page key, file or title; same hero slug; same title in the same gallery category.
  • Editing a record without changing its name is always allowed, even if an identical copy existed before these checks were added.
  • Double clicks: Save buttons lock while saving. A booking or payment submitted twice is saved once; the second click shows "already created" or "already recorded". Deliveries, stock counts, wastage and purchase orders sent twice within a few seconds are treated as one.
  • Required fields, number ranges (for example prices of 0 or more, percentages 0–100) and dates are checked on the server too, so a form cannot be saved half-filled.
