Room Prices, Rate Plans and Packages

This guide covers three places that decide what a guest pays for a room at Rosalyns Beach Hotel: the room prices on the Rooms page, automatic price changes on the Rate Plans page, and optional extras on the Packages page.

How a booking price is worked out

The same steps are used on the website booking form and in the admin when staff create a booking.

  1. The system picks the nightly room price from the number of guests sharing the room: the Single Occupancy Price for 1 guest, the Double Occupancy Price for 2, the Triple Occupancy Price for 3. If that price is left empty, the Price Per Night is used instead.
  2. Any matching, active rate plan then raises or lowers that nightly price.
  3. The nightly price is multiplied by the number of nights.
  4. If children are staying, a child supplement is added: the nightly price after the rate plan, times the Child Supplement (%), times the number of children, times the number of nights.
  5. If VAT or the tourism levy is switched on in Hotel Settings, they are worked out on the stay amount and added. The tourism levy is not charged on packages.
  6. Any packages the guest ticked are added on top.

Example: a double room has a Double Occupancy Price of MWK 100,000. A 10% discount rate plan matches, so the night costs MWK 90,000. Two nights is MWK 180,000. One child with a Child Supplement of 50% adds 90,000 × 50% × 2 nights = MWK 90,000.

What is on the screens

Rooms page (Manage Hotel Rooms)

  • Add New Room button at the top.
  • Joined Rooms button (opens the joined-rooms screen).
  • One card per room type. Each card shows the price per night, then Single, Double and Triple prices (only those that are filled in) and Child: +50% style supplement. It also shows an Active or Inactive badge and a Featured badge.
  • Small icon buttons on each card: change featured image, manage gallery photos, room video, active on/off, featured on/off, post to Facebook (only if Facebook posting is on), and delete.
  • Edit Room button on each card.
  • The text Drag cards to reorder.

Rate Plans page

  • New Rate Plan button.
  • A short box called How it works.
  • One card per plan, highest priority first. Each card shows the name, the type (Seasonal, Weekend, Length of Stay, Last-Minute, Early Bird or Promotion), the change (for example -10% or +20%, or an amount in MWK), the condition (dates, days, nights or days before arrival; Always active for a Promotion), All room types or Selected rooms, Priority and Stacking if it stacks. Inactive plans look faded.
  • Three buttons on each card: edit (pencil), activate or deactivate (toggle), delete (bin).
  • If there are no plans you see "No rate plans yet. Create your first one to start applying dynamic pricing."

Packages page (Room Packages)

  • New Package button.
  • A short box called How it works: packages appear as optional add-ons on the booking form, guests tick them before submitting, and the cost is added to the booking total.
  • One card per package, shown in Sort Order. Each card shows the name, a Featured badge if set, and the price (for example MWK 15,000 per night). A package priced at 0 shows Complimentary and FREE. The card also shows All rooms or 2 room type(s), the short description, and up to 6 inclusions (then +3 more).
  • Three buttons on each card: edit, activate or deactivate, delete.
  • If there are no packages you see "No packages yet. Create your first package to offer guests extras like breakfast or spa access."

How to add a room type

A room type is a kind of room (for example Deluxe Double) that guests book. The individual physical rooms are managed under Advanced → Individual Rooms.

  1. Open Settings → Rooms and click Add New Room.
  2. Under Room Information fill in Room Name (required), Short Description, Full Description and Featured Image URL / Path (optional; you can also upload a picture afterwards with the image button on the card).
  3. Under Pricing fill in Price Per Night (required). Fill in Single Occupancy Price, Double Occupancy Price and Triple Occupancy Price if the price changes with the number of guests (see the next section). Set Child Supplement (%) (it starts at 50). Tick Enable Triple Occupancy (3 guests) if the room can take three guests. Leave Allow Children for this Room Type ticked if children may stay (it is ticked to start with).
  4. Under Room Details fill in Size (sqm), Max Guests, Bed Type, Rooms Available (starts at 1), Total Rooms (starts at 1), Display Order and Amenities (comma-separated).
  5. Under Video (Optional) you can paste a Video URL (YouTube, Vimeo, Dailymotion or a direct video link).
  6. Under Status tick Featured Room if you want it shown on the homepage.
  7. Click Add Room. You will see "New room added successfully!" inside the window and the new card appears behind it. Click Close when finished.

A new room is always created as Active. The Add window has no Active tick box. To hide it, use the active on/off icon on its card afterwards.

How to change room prices

  1. Open Settings → Rooms and click Edit Room on the room.
  2. Go to the Pricing section. The window title reads Edit: [room name].
  3. Change the prices you need:
    • Price Per Night — required. Used whenever a more specific price below is empty.
    • Single Occupancy Price — one guest in the room. Optional.
    • Double Occupancy Price — two guests. Optional.
    • Triple Occupancy Price — three guests. Optional.
    • Child Supplement (%) — each child pays this percentage of the nightly price. 50 means half. The highest you can set is 100; a larger number is saved as 100.
  4. Tick or untick Enable Triple Occupancy (3 guests) and Allow Children for this Room Type as needed.
  5. Click Save Changes. You will see "Room updated successfully!" inside the window.

Prices are in Malawi Kwacha (MWK). Rate plans change these prices automatically; do not edit room prices just to run a short promotion. Use a rate plan so the normal price comes back by itself.

How to hide, feature, reorder or delete a room

  1. Hide or show: click the active icon on the card. Hovering shows "ACTIVE — visible to guests. Click to deactivate." or "INACTIVE — hidden from guests. Click to make live." The page reloads. You can also untick or tick Active under Status in Edit Room.
  2. Feature on the homepage: click the star icon on the card. You can also use Featured in Edit Room.
  3. Change the order: drag the cards into the order you want. You can also type a number in Display Order in Edit Room.
  4. Delete: click the bin icon. Confirm the question Delete "[room name]" permanently? This removes all images, videos and data. Cannot be undone.

A room type that has ever had a booking cannot be deleted. Deactivate it instead.

How to create a rate plan

A rate plan raises or lowers the nightly room price automatically when a booking matches its conditions. Use a minus number for a discount and a plus number for an extra charge.

  1. Open Settings → Rate Plans and click New Rate Plan.
  2. Type a Plan Name (required, up to 100 characters), for example Festive Season Surcharge.
  3. Choose a Rule Type (required). The fields below change to match:
    • Seasonal (date range) — fill in Start Date and End Date. The plan applies when the check-in date falls inside this range. Both dates are required.
    • Weekend (day of week) — tick one or more days (Sun to Sat). The plan applies if any night of the stay falls on a ticked day. You must tick at least one day.
    • Length of Stay — fill in Minimum Nights and, if you want, Maximum Nights (optional). You need at least one of the two.
    • Last-Minute — fill in Min Days Before Arrival and Max Days Before Arrival. Example: min 0, max 3 means the guest books within 3 days of arrival.
    • Early Bird — fill in Min Days Before Arrival and, if you want, Max Days Before Arrival (optional). Example: min 30 means the guest books at least 30 days ahead.
    • Promotion (always) — no conditions. It applies to every stay while it is active.
  4. Optionally type a Description (optional). It is a note for staff only and is not shown to guests.
  5. Choose the Adjustment Type: Percentage (%) or Fixed Amount (MWK).
  6. Type the Adjustment Value (required). A negative number is a discount and a positive number is a surcharge. Example: -10 is 10% off, +20 is a 20% surcharge. A fixed amount of -15000 takes MWK 15,000 off each night.
  7. Choose Applies To: All Room Types or Selected Room Types Only. If you choose the second, tick the room types under Select Room Types. Only active room types are listed.
  8. Set Priority (0–255). A higher number is checked first.
  9. Under Options, switch Stack with other plans on if this plan may combine with others, and leave Active on for the plan to start working.
  10. Click Save Rate Plan. You will see "Rate plan created successfully." inside the window, and the card appears on the page behind it. Click Close when finished.

If the new plan overlaps another active plan of the same type, the message adds Note: it overlaps active plan(s) of the same type: [names]. Guests get the single best price if any overlapping plan is non-stacking. The plan is still saved.

When more than one plan matches a booking

  • If at least one matching plan does not stack, only the single plan that gives the lowest price is used. The others are ignored.
  • If every matching plan stacks, all of them are applied one after the other, highest priority first.
  • The price never goes below 0.
  • Example: a stay matches a Weekend plan of +10% (stacking) and a Promotion plan of -5% (stacking). MWK 100,000 becomes 110,000 and then 104,500.

How to edit, switch off or delete a rate plan

  1. Edit: click the pencil button on the plan. Change the fields and click Save Rate Plan. You will see "Rate plan updated successfully."
  2. Switch off or on: click the toggle button on the plan. You will see "Rate plan deactivated." or "Rate plan activated." A switched-off plan is never applied to bookings.
  3. Delete: click the bin button. The window asks Delete rate plan "[name]"? This cannot be undone. Click Yes, Delete (or Cancel). You will see "Rate plan deleted."

To stop a plan for a while and bring it back later, switch it off instead of deleting it.

How to create a package

A package is an optional extra (for example breakfast) that a guest can tick on the booking form. Its cost is added to the booking total.

  1. Open Advanced → Packages and click New Package.
  2. Under Identity type the Package Name (required, up to 100 characters), for example Bed & Breakfast.
  3. Choose an Icon (Font Awesome class) if you want, for example fas fa-coffee (up to 60 characters). If you leave it empty, a gift icon is shown.
  4. Type a Short Description (up to 255 characters, shown on the booking form) and, if you want, a Full Description (optional).
  5. Type the Inclusions (one per line). Each line appears as a tick on the booking form.
  6. Under Pricing choose the button Priced Add-on or Complimentary (FREE). With Complimentary the hint reads This package will be offered at no charge to guests.
  7. For a priced package choose the Price Type and type the Price Amount (MWK):
    • Per Night — amount × number of nights.
    • Per Stay (flat fee) — the amount once for the whole stay.
    • Per Person Per Night — amount × number of adults × number of nights.
  8. Under Scope & Visibility choose Applies To: All Room Types or Selected Room Types Only (then tick the room types).
  9. Type a Sort Order. A lower number is shown first on the booking form.
  10. Switch Featured (shown prominently) on if you want it highlighted, and leave Active on for guests to see it.
  11. Click Save Package. You will see "Package created successfully." Click Close when finished.

Example: breakfast at MWK 15,000, Per Person Per Night, for 2 adults staying 3 nights costs 15,000 × 2 × 3 = MWK 90,000.

How to edit, switch off or delete a package

  1. Edit: click the pencil button on the package, change the fields and click Save Package. You will see "Package updated successfully."
  2. Switch off or on: click the toggle button. You will see "Package deactivated." or "Package activated." A switched-off package is not offered to guests.
  3. Delete: click the bin button and confirm Delete package "[name]"? Guests with existing bookings will keep it, but new bookings won't see it. You will see "Package deleted."

Rules the system enforces

  • Changes to a room, rate plan or package affect new bookings only. Existing bookings keep the price they were made with, and packages already on a booking stay on it.
  • A room type needs a name. Rooms Available cannot be more than Total Rooms when you edit a room ("Availability cannot exceed total rooms."). When you add a room, an Available number above Total is lowered to match Total.
  • The triple tier can only be switched on when Max Guests is 3 or more. Single and double tiers are on when Max Guests allows them (1 and 2 or more).
  • If Allow Children for this Room Type is not ticked, a booking with children for that room is refused. The message starts "Children are not allowed".
  • If Single, Double or Triple Occupancy Price is left empty, the Price Per Night is used for that number of guests.
  • Rate plans only change a nightly price above 0. A percentage cannot be -100 or lower, or above 1000. A fixed amount cannot be more than 9,999,999 either way. The adjustment cannot be 0.
  • A seasonal plan is matched on the check-in date only. A plan that is switched off, or that does not match the stay, does nothing.
  • The "days before arrival" is counted from today to the check-in date. A check-in date in the past counts as 0.
  • A rate plan or package set to Selected Room Types Only must have at least one room type ticked.
  • Package price must be between 0 and 99,999,999.99. A price of 0 is shown as Complimentary.
  • A guest can only choose packages that are active and apply to the room they picked.
  • You need the Room Management permission for the Rooms page and the Hotel Settings permission for Rate Plans and Packages.
