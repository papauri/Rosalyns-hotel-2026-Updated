Guide 01 · Cashier

POS Till

Your home screen for the restaurant, bar and coffee shop. Every order starts here.

URL /admin/pos.php Role restaurant_staff · manager · admin Read time 5 min

Layout (left → right)

Pane Purpose
Left — Categories All menu sections (Starters, Mains, Drinks…). Tap one to filter.
Centre — Items Tap an item to add it to the cart. Counts (e.g. 23 items) are visible per category.
Right — Cart & Pay Current order, quantities, totals, payment buttons, park-as-tab.

The top Till Bar always shows: cashier name, today's order count, today's revenue, today's cash collected, plus links to Stations (KDS/BDS/CDS feed), Restaurant Orders, and Sign Out.

Take an order

  1. Pick the destination — choose a Table number (dine-in), Room number (room charge / room service) or leave blank for takeaway.
  2. Pick a category on the left.
  3. Tap items in the centre — each tap adds 1; tap + / − in the cart to adjust qty.
  4. Review the cart total at the bottom-right.
  5. Choose action:
    • Pay & Send (walk-in/takeaway) — pay now, then fire immediately to KDS/BDS/CDS.
    • Fire to Stations (or Send to Kitchen / Send to Bar, based on cart mix) — opens the order as a tab to settle later.
    • Settle from Tabs (dine-in) or Room Folio (room service) — the pay button guides you to the correct settlement path.
    • Open tabs can be re-opened later from the Tabs panel and add more items, then settle.
  6. Choose payment method: Cash · Mobile Money · Card.
    • Mobile Money requires provider + transaction reference.
    • Card requires last 4 digits + authorisation code.
  7. The success overlay shows the order reference. Print or hand the receipt to the guest.

Tabs (parked orders)

  • A parked tab stays open until you settle it.
  • The Tabs tray shows: reference, table/room, order type, item count, total, age timer (turns red after 30 min), fired time, served time, and current kitchen status (pending / prep / ready / collection / served counts).
  • Tap Settle to add payment & close.
  • Tap Details to open the full order detail modal. Inside you'll see:
    • Order Lifecycle track — five milestone steps (Placed → Fired → Ready → Served → Paid) with icons, timestamps, and colour-coded dots: green for completed steps, primary colour for the current active step.
    • Item Status stepper — how many items are at each kitchen stage (pending / preparing / ready / collecting / served).
    • Line items table with per-item kitchen status and timestamps.
    • Audit & event log — every action on this order in chronological order.
  • For settled tabs, use Receipt to open the printable receipt page.
  • Admin/manager tab cards also show a Lifecycle link that opens /admin/order-lifecycle.php in a full page with Cancel and Void actions.

How stock works

  • Stock is not deducted when you fire an order. It is deducted when the kitchen/bar/coffee station marks each item Ready (preparation complete).
  • This means a Cancel Before Prep never needs to restore stock — nothing was taken yet.
  • A Void on a partially-prepared order only restores stock for items that had already been marked Ready.
  • The POS shows a ready alert from each station when all their items are ready or in the collection queue.

My Orders tracker

The My Orders panel (bottom-left of the POS till) shows every live order you have fired this shift, refreshed every second so KDS/BDS/CDS changes appear almost immediately.

Element What it means
⚡ RUSH badge This order has been marked high-priority. All stations see it highlighted in red.
Station pips (🍳 · 🍺 · ☕) One pip per station. Green tick = all items at that station done. Blue spinner + count = items still in progress.
Amber italic note The order note currently visible on all station screens.
Small item summary Shows the ordered items in small text. Long orders show the first few items plus a remaining count.
Rush button Toggles priority on/off. All stations get an instant URGENT inbox message when you set or clear Rush.
Edit note button Opens a text overlay to update the order note. All stations receive an URGENT inbox message with the new text the moment you save.
Rush and Edit note are only available while the order is in placed status (kitchen not yet done). Once all stations have served, the buttons disappear.

Station replies & notifications

  • When kitchen/bar/coffee sends a note back, you get an in-app notification and sound alert on POS.
  • Use Sounds / Sound Settings to choose the normal alert, urgent alert, and volume for the till device.
  • Direct station messages (for your user) appear in the POS inbox as Station → You.
  • When all items at a station are Ready or in Collection, POS shows a ready-collection alert with the item summary. The cashier who placed the order gets a vibrating urgent banner ("🔔 Your order is ready!"). Other POS sessions get a quieter green banner.
  • Ready and station-message popups stay on POS for 2 minutes and can be closed immediately with the × button.
  • If a tab was already paid elsewhere, stock is short, or there is nothing pending, POS shows a friendly dialog and refreshes the affected tray instead of leaving the cashier guessing.
  • Important action buttons include a brief click lock to prevent accidental double taps.

Cancelling an order before prep

If you realise a mistake immediately after firing — and the kitchen/bar has not started yet — you can cancel without involving a manager.

  1. Open the Tabs tray.
  2. Find the order. If all items are still pending (none started), a red Cancel (Before Prep) button appears.
  3. Enter a reason of at least 8 characters (logged for audit).
  4. The order is removed from all station boards. Because no stock was deducted yet, nothing needs restoring.
Once the kitchen or bar taps Start or Ready on any item, the Cancel Before Prep button disappears. You must use Void (manager) instead.

Voiding an order manager only

  1. Open the Tabs tray and find the order, or open it from Restaurant Orders.
  2. Tap Void & restore stock.
  3. Type a reason of at least 8 characters (saved for audit).
  4. Stock is restored for any items that had already been prepared (marked Ready on KDS). Payment is cancelled and the order is removed from KDS/BDS/CDS automatically.

Closing your shift (Z-report)

  1. Tap Close Shift in the till bar (visible from cashier role and above).
  2. Type your counted cash drawer total.
  3. The variance is calculated automatically.
  4. If variance > tolerance, an admin override + reason ≥ 5 chars is required.
  5. Confirm. A Z-report is saved and you are signed out.

Tips

The Till works offline — your orders queue locally and sync when the internet returns.
  • All hard buttons are at least 44px tall — designed for touch.
  • Press ? on a keyboard to see the help bubbles.
  • Fullscreen kiosk mode — on first load a small banner at the bottom says "Tap anywhere to go fullscreen". Tap anywhere and the browser enters full-screen, hiding tabs and the address bar. If you accidentally exit (e.g. back-swipe), the banner reappears and the next tap re-enters it automatically.
