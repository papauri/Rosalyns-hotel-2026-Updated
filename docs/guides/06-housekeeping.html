Guide 06 · Housekeeping

Housekeeping

Track every individual room's Pending / In Progress / Completed / Verified / Blocked status. Every change is logged with old → new state and timestamp.

URL /admin/housekeeping.php Role housekeeping · manager · admin Read time 5 min

Assignment statuses

Housekeeping work is tracked as assignments against a room (not a single room-wide status flag). Each assignment moves through:

Status Meaning
Pending Task created, not yet started.
In Progress Housekeeper has tapped Start — currently cleaning.
Completed Housekeeper marked the task done.
Verified Supervisor confirmed the completed task — locked, cannot be edited further.
Blocked Task cannot proceed (e.g. maintenance issue) — set via the assignment's status field.

A typical morning

  1. Sign in. The All Assignments table lists every task, filterable by status and searchable by room or staff name.
  2. On a Pending row, tap Start → status moves to In Progress.
  3. When done, tap Mark Done → status moves to Completed.
  4. The supervisor reviews completed rows and taps Verify to mark the task Verified — this cannot be undone.

Maintenance issues

  1. Set a task's status to Blocked if the room can't be cleaned due to a maintenance issue, and add a note explaining why.
  2. Serious out-of-order rooms (unbookable until fixed) are handled on the separate Room Maintenance page, which removes the room from bookable inventory.

Audit history

  • Every status change is saved to housekeeping_audit_log.
  • Tap View History on an assignment row to see who changed it, when, and what changed.

Tips

If a guest reports an issue with a room, create or edit an assignment for it and set the status appropriately — this keeps the room on staff's task list.
