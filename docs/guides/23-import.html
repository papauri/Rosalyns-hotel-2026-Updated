Import a stock list

Import brings a stock list in from a spreadsheet, so you do not have to type every item by hand. It is a bulk way to add stock items, and it can file your opening stock from the spreadsheet. You upload the file, check how each column and row was read, answer anything that is unclear, and then press Confirm. Nothing is saved to your stock until you do, and the opening stock count then waits for a second manager to approve it.

Import ships switched off. An administrator has to switch it on first (see Who can use it). Until then the Import page is not shown in the menu.

Who uses it
Administrators and managers, and anyone who has been given the Import permission. They also need Ingredients & Recipes.
Where to find it
Admin menu → Stock → Import. The button is also called Import on the page.
Permission needed
Import and Ingredients & Recipes. Both are needed. Administrators have everything.
Only shown when
Data Import: on/off is switched on in Settings → Modules (administrators only), and the Stock & Inventory module is on.

What Import is: bulk add stock and opening stock from a spreadsheet

Import reads a stock list from an Excel or CSV file and brings the items into Ingredients. It works out which columns hold the item name, the balance, the unit, the price and the expiry date. Where it is not sure, it asks you. It never invents a value and never guesses one.

  • Accepted: Excel files (.xlsx and .xlsm), and CSV or TSV text files (.csv and .tsv).
  • Not supported yet: Word files, PDF files and old Excel files (.xls). Open the file in Excel, use Save As → Excel Workbook (.xlsx), then upload that copy.
  • Largest file: the upload screen shows the biggest size the hotel accepts.
  • Macros never run. A formula is read only as the value it last showed.
  • Stock lists only for now. Import does not bring in anything else.

Who can use it, and how to switch it on

Only an administrator can switch Import on or off.

  1. Open Admin menu → Settings → Modules.
  2. Find the card Data Import: on/off. Only administrators see this card.
  3. Switch it on. Switching it off hides Import at once. Nothing half-imported is kept.

Once it is on, administrators and managers can use it by default. To give it to someone else, or take it away, open Admin menu → Settings → Staff & Access, open the person's permissions, and tick or untick Import. The person also needs Ingredients & Recipes. Without it the Import menu item does not show for them.

If something goes wrong: "Import is switched off for this hotel." means an administrator has not switched it on. "Your account cannot use Import. It needs the Import and the Ingredients & Recipes permissions." means your account is missing one of them. Ask an administrator.

How to import a stock list, in four steps

Open Admin menu → Stock → Import. The page has four steps, shown across the top: Upload, What we found, Review & answer and Confirm.

Step 1: Upload your stock list

  1. Drop your file on the box, or click Choose file and pick it.
  2. Click Upload and read the file. The file is only read. It is never changed.

Step 2: What we found

This shows how the file was read. Nothing has been saved yet. For each sheet you see:

  • Sheets read, Sheets to import and Items found, with the total number of stock rows.
  • Total lines left out: summary lines such as totals.
  • Columns not imported: calculated columns such as totals, days to expiry and status.
  • A card for each sheet, with the columns that were understood and the ones left out, and why. A sheet that does not look like a stock list says so under Why.

Check this list, then click Continue to review. If a sheet or column needs an answer first, the page shows the question inside that sheet's card.

Step 3: Review and answer

Each line is one stock item as it would be imported. The grey tag under each value shows the cell it was read from. Use the filter buttons to show only the rows that Need answer. Pick one answer for each question. The page updates after every answer. Your answers are kept if you leave the page and come back.

  • Click Download what will be imported (CSV) to check the ready items in Excel before you confirm.
  • Use Go to step 2 if a question is about how a sheet was read.

Step 4: Confirm

This is the last check. It shows the numbers for the whole file:

  • New ingredients: items not in your stock yet. They will be created.
  • Existing items updated: existing items where you ticked a field to change.
  • Existing items left as they are: matched to an item already in stock, with nothing ticked.
  • Lines in the opening count: items with stock and a price.
  • Rows skipped: rows you skipped, or rows that are not items.
  • Still need an answer: questions to sort out first.

Press Confirm and import. The result page shows Ingredients created, Ingredients updated, Rows skipped, Opening count lines and Expiry batches. Use Open the opening count to see the count that is waiting for approval.

My imports. At the bottom of the page is a list of the imports you started in the last 30 days. An administrator sees everyone's. Open one to carry on where you stopped, or cancel one you no longer need.

What the questions mean

Import asks a question only when something is unclear. Every question has a few answers to pick from. The page does not pick one for you. Confirm stays off until every question is answered.

The questionWhat it meansYour options
"Did you mean …?"The name in your file is not in stock yet, but a very similar name is. For example Budwiser for Budweiser.Yes, use the existing "…" adds the row to that item. No, … is a new/different item creates a new ingredient.
Batches or duplicate?The same item name is on two or more rows.Separate batches of the same item (import all): one item with two batches, for example B1 and B2. A duplicate: import it once (skip the later rows): the second row is left out.
Which price?The same item has two different prices, from two sheets or two rows.Pick one price. Each option shows the value and the cell it came from. Nothing is averaged, and the other price is not used.
Per case or per unit?The price looks like the price of a whole case, not of one bottle or one kilo.Price of one unit (import as written), or Price of a whole case/pack (I will enter the pack size). If you choose the case, type how many units are in it. The price is then shown as "per case of 12 = 5,000 each".
"Is 28,750 right?"Import compares each price with what this hotel has paid for that item before, and with similar items. If the price in the file looks off, it asks, and says the likely reason (for example an extra zero, or a case price typed as a unit price). There is no fixed limit: what counts as unusual follows your own prices. An item with no history is not asked, and a price is only checked when it would actually be applied (a new item, or an existing item whose cost you ticked). Prices are shown as written; VAT is not added or removed.The file's price is right, Keep the current price (the cost is left alone, the quantity still imports) or Skip this row. A price too large for the database to store is blocked: fix the cell and upload again, or skip the row.
Which unit?A sheet has no unit column, so Import does not know if its items are bottles, kilos or something else.Pick the unit from the list. Import never picks one for you.
"Is it a category heading, or an item that is out of stock?"A row has zero in every column. It could be a heading for the rows below, or an item with nothing left.An item (out of stock), or A category heading for the rows below.
"… Should it be imported?"A sheet has item columns, but its name sounds like a summary or dashboard sheet.Yes, import it, or No, skip it.
"Which column … holds the item names?"Import cannot find the item-name column on a sheet.Pick the column from the list.

When you fix a name, Import remembers the fix for next time. It shows it as a pre-filled answer with the note "Remembered from an earlier import. Change it if it is wrong." It is never applied without showing you first.

The grey source tag, and what is left out on purpose

Every value on the review screen has a small grey tag such as Bar!D12. That is the sheet name, then the cell the value was read from. If a value does not match your file, check that cell first.

Import leaves these out on purpose:

  • Dashboards and summary sheets. They are skipped, and Step 2 says why.
  • Category heading rows, such as a row that only says the name of a group. Import uses them to file the items below. A heading is never an item.
  • Total lines, such as TOTAL or GRAND TOTAL. They are never imported.
  • Calculated columns: totals, days to expiry, status, purchase quantity and total cost. They are shown greyed out and never imported. The real numbers are taken from the columns you typed.

Nothing is invented or guessed. A value that is not in your file cannot reach stock. A formula with no stored result is left blank, never read as 0.

What Confirm does to your opening stock

Confirm is one step, and it is all or nothing. If anything fails, nothing is saved, and the page says "Nothing was imported."

  1. New ingredients are created. Each one takes its category from the heading above it (or the sheet name), its unit from the sheet, and its price as the cost.
  2. Existing items keep their values. Only the fields you ticked are changed. Their unit is never changed.
  3. The stock quantities are filed as one opening stock count. They are not added to your stock yet. A different manager must approve that count in Stock Count first. Only then does the stock appear.
  4. Nothing is deleted, and recipes are not touched.
  5. The copy of your file on the server is deleted afterwards.
  • Prices are taken as written. VAT is not added or removed.
  • An item with stock but no price is created without a cost, and its stock is left out of the opening count. The page says "Add the cost later."
  • Who approves the count. A different manager must approve it while the rule Stock count: a second person must approve is on, which is the default. If an administrator has switched that rule off, the person who imported can approve the count. See Stopping stock going missing.

Confirm is turned off while any question still needs an answer. The page says "Some questions still need an answer." Answer them on Step 3, or skip the row, and Confirm turns on.

Importing the same file twice, cancelling, and clean-up

  • The same file again is blocked. The page says "This file was already imported on … by …". Only an administrator can import it again, by ticking Import again on the upload step.
  • Cancel. Click Cancel this import on Steps 2 to 4. The page says "Nothing has been saved to your stock, and the uploaded copy will be deleted." Confirm the cancel, and the page says "The import was cancelled and the uploaded copy deleted."
  • Clean-up. The uploaded copy is kept on the server only while you work on it. It is deleted when you finish, when you cancel, or after 7 days.

If something looks wrong

  • "Word and PDF files are not supported yet." Open the file in Excel, use Save As → Excel Workbook (.xlsx), and upload that.
  • "This is an old Excel file (.xls)." Save it again as an Excel Workbook (.xlsx), then upload that copy.
  • "That file is bigger than this server accepts." Save a smaller copy. You can remove old sheets you do not need.
  • "The file could not be read." Open the file in Excel to check it, save it again as .xlsx, and upload again.
  • "Your session has expired. Reload the page and try again." Reload the page and sign in again if asked.
  • "Row 12: Unit price in D12 is "abc", which is not a number. Fix it in the sheet and upload again, or skip this row." Fix the cell in your file and upload the file again, or skip that row on Step 3.
  • "… is negative. Negative amounts are not imported." Fix the cell in your file and upload again, or skip that row.
  • "Sheet … has no column headings I recognise." Skip that sheet, or make sure its column headings say what they hold (for example Item, Balance, Unit Price).
  • A sheet or column is missing from Step 2. Look at Columns not imported and the reason on the sheet's card.
  • A row says Need answer and Confirm stays off. Answer the question on Step 3, or skip that row.
  • Stock did not change after Confirm. That is expected. The quantities wait in the opening count. Ask a different manager to approve it in Stock Count.
  • "This file was already imported on …" Ask an administrator, if the file really must come in again.
