Import a stock list

Import brings a stock list in from a spreadsheet, so you do not have to type every item by hand. It is a bulk way to add stock items, and it can file your opening stock from the spreadsheet. You upload the file, check how each column and row was read, answer anything that is unclear, and then press Confirm. Nothing is saved to your stock until you do, and the opening stock count then waits for a second manager to approve it.

Import ships switched off. An administrator has to switch it on first (see Who can use it). Until then the Import page is not shown in the menu.

Who uses it
Administrators and managers, and anyone who has been given the Import permission. They also need Ingredients & Recipes.
Where to find it
Admin menu → Stock → Import. The button is also called Import on the page.
Permission needed
Import and Ingredients & Recipes. Both are needed. Administrators have everything.
Only shown when
Data Import is switched on in Settings → Modules (administrators only), and the Stock Management switch is on.

What Import is: bulk add stock and opening stock from a spreadsheet

Import reads a stock list from an Excel or CSV file and brings the items into Ingredients. It works out which columns hold the item name, the balance, the unit, the price and the expiry date. Where it is not sure, it asks you. It never invents a value and never guesses one.

  • Accepted: Excel files (.xlsx and .xlsm), and CSV or TSV text files (.csv and .tsv).
  • Not supported yet: Word files, PDF files and old Excel files (.xls). Open the file in Excel, use Save As → Excel Workbook (.xlsx), then upload that copy.
  • Largest file: the upload screen shows the biggest size the hotel accepts.
  • Macros never run. A formula is read only as the value it last showed.
  • Stock lists only for now. Import does not bring in anything else.

Who can use it, and how to switch it on

Only an administrator can switch Import on or off.

  1. Open Admin menu → Settings → Modules.
  2. Find the card Data Import. Only administrators see this card.
  3. Switch it on. Switching it off hides Import at once. Nothing half-imported is kept.

Once it is on, administrators and managers can use it by default. To give it to someone else, or take it away, open Admin menu → Settings → Staff & Access, open the person's permissions, and tick or untick Import. The person also needs Ingredients & Recipes. Without it the Import menu item does not show for them.

If something goes wrong: "Import is switched off for this hotel." means an administrator has not switched it on. "Your account cannot use Import. It needs the Import and the Ingredients & Recipes permissions." means your account is missing one of them. Ask an administrator.

How to import a stock list, in four steps

Open Admin menu → Stock → Import. The page has four steps, shown across the top: Upload, What we found, Review & answer and Confirm.

Step 1: Upload your stock list

  1. Drop your file on the box, or click Choose file and pick it.
  2. Click Upload and read the file. The file is only read. It is never changed.

Step 2: What we found

This shows how the file was read. Nothing has been saved yet. For each sheet you see:

  • Sheets read, Sheets to import and Items found, with the total number of stock rows.
  • Total lines left out: summary lines such as totals.
  • Columns not imported: calculated columns such as totals, days to expiry and status.
  • A card for each sheet, with the columns that were understood and the ones left out, and why. A sheet that does not look like a stock list says so under Why.

Check this list, then click Continue to review. If a sheet or column needs an answer first, the page shows the question inside that sheet's card.

Step 3: Review and answer

Each line is one stock item as it would be imported. The grey tag under each value shows the cell it was read from. Answer the questions that sit under an item. The page updates after every answer, and your answers are kept if you leave the page and come back.

At the top of the step you will see:

  • A progress bar with a line such as "12 of 40 questions answered".
  • Jump to the next one that needs an answer. The button goes to the next item that still needs you, and shows how many items are left. If nothing is left, it says Nothing is waiting for an answer. When you are not typing, the N key does the same as the button.
  • Search items. Type part of an item name, a category, or a cell from your file. C12 finds that cell. BAR!C12 finds cell C12 on the sheet called BAR. Every word you type must match.
  • Status buttons. All, Needs answer, Blocked, Ready and Skipped, each with a count. While anything still needs an answer, the list starts on Needs answer and Blocked. Blocked rows cannot be imported as written; see Blocked rows. Skipped rows have been left out on purpose.
  • Show as. List shows one list. By category groups the items under their category headings.
  • More ways to narrow it. This opens the filter panel. On a phone it opens as a drawer.

The filter panel has these choices:

  • Sheet and Category: only items from one sheet (tab) of your file, or under one heading.
  • Kind of question: only items that still have an unanswered question of that kind.
  • New or existing: new items, which are created when you confirm, or existing items, which match something already in stock.
  • Sort by: file order, name A to Z, needs answer first, category, or price (lowest first or highest first). Items that tie stay in the order of your file.
  • Items per page: 25, 50, 100 or 200.
  • Four tick boxes: Has a warning, Cost change ticked, Already has stock and I answered a question.

Each number next to a choice shows how many items match it with your other filters. Press Show items or Done to close the panel and keep your filters. Press Clear filters to remove them all.

Your place is kept. Your filters are kept in the web address. If you reload the page, or come back to it, you stay where you were. Changing a filter does not add a step to the Back button.

By category. Each category heading shows its item count, how many items need an answer, and how many are skipped. Press a heading to open it. Its items load when you open it. Up to eight categories can be open at once. Opening a ninth closes the one you opened first.

Use the page buttons at the bottom of the list to move between pages.

  • Click Download what will be imported (CSV) to check the ready items in Excel before you confirm.
  • Use Go to step 2 if a question is about how a sheet was read.

On a phone (a narrow screen), each item is shown as a stacked block: the item name at the top, then each value with its label above it, then the questions and buttons for that item. Scroll down the block to answer.

Step 4: Confirm

This is the last check. It shows the numbers for the whole file:

  • New ingredients: items not in your stock yet. They will be created.
  • Existing items updated: existing items where you ticked a field to change.
  • Existing items left as they are: matched to an item already in stock, with nothing ticked.
  • Lines in the opening count: items with stock and a price.
  • Rows left out: rows you left out, or left out because of an answer. They are listed below.
  • Fixed for you: small format fixes made while reading the file. Each one is listed below, with Undo.
  • Still need an answer: questions and blocked rows to sort out first.

Below the numbers, Step 4 lists the rows left out, then the fixes. See Rows left out and Fixed for you.

Press Confirm and import. The result page shows Ingredients created, Ingredients updated, Rows skipped (rows that are not items, or were left out), Left out by you, Fixed for you, Opening count lines and Expiry batches. Use Open the opening count to see the count that is waiting for approval. Press Download the updated stock workbook for an Excel copy of your stock (see Export your stock to Excel).

My imports. At the bottom of the page is a list of the imports you started in the last 30 days. An administrator sees everyone's. Open one to carry on where you stopped, or cancel one you no longer need. Press Download on a row to get the original file back, with its original name. The Download button shows only while the hotel still keeps its copy. That copy is deleted when the import is confirmed, cancelled or after 30 days, and then the button is gone. Only the person who uploaded the file, or an administrator, can download it.

The "Which unit?" question for a sheet lists the items it covers, each with its name, row, cell and category.

When you fix a name, Import remembers the fix for next time. It shows it as a pre-filled answer with the note "Remembered from an earlier import. Change it if it is wrong." It is never applied without showing you first.

If the Assistant is switched on you can ask it what a question means or why Confirm is blocked; it only explains — you answer on the Import screen. It also needs Use the Assistant. See The Assistant.

Choosing units for new items, and the suggestions

A sheet often has no unit column, so Import does not know how its new items are counted. You choose the unit. Import may suggest one, but it never uses a suggestion until you click it.

  1. Open the question "Which unit?" in Step 3. It lists the new items on that sheet that have no unit yet. Each item shows its name, its row, its cell and its category.
  2. For one item, open its drop-down Choose a unit… and pick the unit. The choice is saved at once. You can change it later: the drop-down then says Change the unit….
  3. To give one unit to every item that has no choice yet, pick a unit under the list, where it says "Or give one unit to every item above that has no choice yet." A unit you chose for a single item is kept.
  4. To find an item, press Show all N items (searchable). Search by name, or use Show to see All, No evidence, Evidence disagrees, Has a suggestion or Already chosen. Press Show fewer to go back to the short list.

What a suggestion looks like. When your own records give a clear answer, the item shows the unit, the reason and a confidence of high or medium. For example: "Suggested: bottle - 9 of the 10 other items under "Beer" are counted in bottle (high confidence, not used until you choose it)." Press the button that says Use bottle (with that item's unit) to take it for that one item.

  • Use the suggestions (N) takes every suggestion on the sheet at once. A box opens first, with the first five item names and how many there are. Only high and medium suggestions are used. Items where the evidence disagrees are not included. You can change any item afterwards.
  • Needs your choice: the evidence disagrees. Two sources say different units, or the other items in the category are split. Import makes no suggestion, and you choose.
  • Needs your choice: nothing in your file or your stock says how this is counted. You choose the unit.

Where a suggestion comes from, in this order:

  1. Your own earlier choice for that item, from a past import (high). See What Import remembers.
  2. An item already in stock with the same name, ignoring size or pack words such as 500ml or x24 (medium).
  3. A unit word in the item name, such as crate or dozen. The word must be a unit your hotel uses.
  4. The other items in the same category. The unit most of them are counted in. High when at least 8 in 10 agree (and there are at least 6 others); medium when at least 7 in 10 agree (and there are at least 3 others).

A size in the name (for example 500ml, 2kg, x24 or pack of 12) never becomes the unit and never sets a pack size. It only backs up a suggestion from the category: it can lift a medium suggestion to high when the item is a container, such as a bottle.

Import only suggests units from your hotel's own unit list. Nothing is used until you click, and nothing changes your stock until you press Confirm.

There is no single undo for the sheet-wide answer. To change one item, pick a new unit from its drop-down. To change many, change them one at a time.

Answering many questions at once

When a list has many questions of the same kind, you can give one answer to all the matching ones, instead of answering each one. You can still change any single answer afterwards.

  1. Use the filters to show the questions you want. For example, pick a Kind of question and a Category. A bulk answer covers every page of the filtered list, not just the page you can see.
  2. Look for the box Answer many at once above the list. It shows only when two or more questions of the same kind are waiting.
  3. Under Which questions, pick the kind. The box shows how many questions are waiting.
  4. Under Answer for all of them, pick the answer.
  5. Press Check and apply…. Nothing is saved yet.
  6. Read the box that opens. It shows how many questions there are, the first five item names, and "… and N more" if there are more. If some questions cannot take that answer, it says so and gives the reasons. Those questions stay as they are.
  7. Press the button at the bottom of the box. It names the answer and the number of rows, for example "Skip 4 rows". Press Cancel to save nothing.

When it has run, the page says how many were applied and how many were refused, with the reason for each refusal. A refused question keeps its own answer. A bulk answer does not change your stock. That only happens when you press Confirm on Step 4.

There is no single undo. To change your mind, change the answers one at a time. The box says this before you press the button.

Questions you answer one at a time. These are not offered for a bulk answer:

  • Questions about a whole sheet or column, such as "Which unit?" for a sheet. Choose the units item by item, or use the sheet-wide choice, as described in Choosing units for new items.
  • Questions that need a typed value, such as the number of units in a case.
  • Questions where you pick one particular name or date from a list, such as which date is right.
  • "Two names for one stock item" questions. Skipping all of them would drop every one of them.

Fixed for you: small fixes, and Undo

Import fixes some small slips for you while it reads the file. A fix only changes how a value is written. It never changes what a number means, and it never guesses a price or a quantity. Each fix is listed in Step 4 under Fixed for you, with:

  • what was fixed, and the item it was for,
  • the cell it came from (for example Bar!D12),
  • the value before and the value after,
  • an Undo button.

The fixes Import makes are:

  • A unit spelled another way. For example btl becomes bottle, LTR becomes L, kgs becomes kg, and pc becomes pcs. This is only done for new items.
  • A quantity typed together with its unit. For example 12 pcs in one cell is read as the number 12 with the unit pcs. A quantity is never converted: 2.5kg is read as 2.5 kg, not as grams.
  • A number with a thousands comma. For example 1,800 is read as the number 1800, as it always was.

Undo puts the value back as written. If it now needs an answer, Import asks you in Step 3. For a number, the cell is no longer read as a number, so its question comes back. Press Fix it again to bring the fix back.

If nothing was fixed, the list is not shown. The result page has a Fixed for you card with the count.

Blocked rows, and skipping rows: why, and what to do

A Blocked row is a row that Import cannot import as written. Blocked rows are not created or changed. They stop Confirm until you deal with them.

Each blocked row shows its plain reason and the exact cell to fix. The reasons are:

The reason you seeWhat to do
A value in the row cannot be used: not a number, negative, a bad date, or a name that is too long.Fix that cell in your file and upload again, or skip the row.
The unit in the file is not the unit this ingredient has in stock.Fix the unit in your file so it matches, or skip the row. Nothing is changed for it.
The name matches an archived ingredient.Restore or rename that ingredient, then upload again, or skip the row. It is left alone.
The name could be several ingredients in stock.Rename it in your file to the exact stock name, or skip it.
The price is too large to be stored.Fix the price cell and upload again, or skip the row.
A name, category or unit is too long.Shorten it in your file and upload again, or skip the row.
Two rows in the file match the same ingredient in stock.Skip all but one of them, or rename them in your file and upload again.
Two different items have the same name.Rename one of them in your file and upload again, or skip it.

For a row with a question, the question card says Cell to fix in your file: and the cell. A row with no question shows its reason in the What happens column.

Skipping a row. Every blocked or unanswered row has a button. It says Skip this item for an item, or Skip this row for a row.

  1. Press Skip this row (or Skip this item). A box opens and lists the rows it will leave out, with the reason and the cell for each.
  2. Press the button at the bottom of the box, for example Leave out 1 row. Press Cancel to keep it.
  3. The page says "Left out 1 row. They are listed in step 4 with the reason, and can be brought back."

Skip all N blocked items… is in the box at the top of Step 3 that says "Some rows are not ready". It shows only when there are blocked rows. It opens the same kind of box: the rows are counted by reason, the first 15 are named with their cell, and you press Leave out N rows to confirm.

Leaving rows out deletes nothing. The row is just not imported. It is listed in Step 4 with the reason. You can bring it back, and you can download it to fix and import later.

Bring it back. Rows you left out yourself have a Bring it back button, in Step 3 and in the list in Step 4. The page says "Brought back 1 row. It is asked again in step 3."

Rows left out (Step 4). Step 4 has a section Rows left out (N). For each row it shows the item, where it is (sheet and cell), and why it was left out. You can:

  • Search it: type an item name, a cell such as C12, or a word from the reason.
  • Filter by Kind, which is one kind of reason.
  • Bring it back for any row you left out yourself.
  • Download skipped rows (CSV) or Download skipped rows (Excel). The Excel file has one tab for each sheet, with the sheet's heading row, then the skipped rows, and Why it was skipped as the first column. Fix the rows in the file, then import it as a new list.

Download the skipped rows before you press Confirm. After Confirm, the uploaded copy of your file is deleted, and the download is refused. The page then says "This import is finished, and the copy of the file was deleted, so the skipped rows can no longer be copied from it."

Continuing without the blocked and unanswered rows

If you cannot fix some rows now, you can leave them out and import the rest. You can do this in two places:

  • In Step 3, in the box "Some rows are not ready": press Continue without the blocked and unanswered rows…
  • In Step 4, where Confirm is turned off: press Continue without them…
  1. Press the button. A box opens and asks first. Its title says how many items will be left out, for example "Continue without 3 items?"
  2. The box lists what will be left out: the counts by reason, the first 15 names, and each one's reason and cell.
  3. Press Leave out N rows to carry on. The page opens Step 4, with the rows listed under Rows left out. Press Cancel to stay where you are.
  4. Confirm still checks everything on the server before anything is saved.

Answer the questions about your sheets first. A question about how a sheet or a column is read (on Step 2) has to be answered first. If one is still open, the page says "Some questions about your sheets are still open" and offers Go to step 2. Each of those questions has its own skip choice on Step 2.

Nothing is deleted. The rows stay in your file. They are listed in Step 4, and you can bring any of them back.

What Import remembers for next time

After you press Confirm and the import is saved, Import remembers what you chose for the new items. It remembers:

  • The unit you confirmed for each new item, whether you picked it, used a suggestion, or chose it for the whole sheet.
  • The category you confirmed for a new item, when you used a category suggestion.
  • A unit for a whole category, when at least three confirmed items in that category agree on one unit.

Next time, the same item name or the same category gets that unit as a suggestion, with the reason "Remembered from your earlier import". It is still not used until you click it or press Use the suggestions.

  • Only what was imported is remembered. Rows you left out teach Import nothing.
  • A cancelled import teaches Import nothing. Nothing is remembered until the import is saved.
  • Spellings such as btl are not remembered. They are fixed from Import's own list.

After a confirmed import, the result page says how many choices were remembered, for example "3 unit or category choices you confirmed will be remembered and suggested next time". There is no screen yet to see or delete a remembered choice.

The grey source tag, and what is left out on purpose

Every value on the review screen has a small grey tag such as Bar!D12. That is the sheet name, then the cell the value was read from. If a value does not match your file, check that cell first.

Import leaves these out on purpose:

  • Dashboards and summary sheets. They are skipped, and Step 2 says why.
  • Category heading rows, such as a row that only says the name of a group. Import uses them to file the items below. A heading is never an item.
  • Total lines, such as TOTAL or GRAND TOTAL. They are never imported.
  • Calculated columns: totals, days to expiry, status, purchase quantity and total cost. They are shown greyed out and never imported. The real numbers are taken from the columns you typed.

Nothing is invented or guessed. A value that is not in your file cannot reach stock. A formula with no stored result is left blank, never read as 0.

What Confirm does to your opening stock

Confirm is one step, and it is all or nothing. If anything fails, nothing is saved, and the page says "Nothing was imported."

  1. New ingredients are created. Each one takes its category from the heading above it (or the sheet name), its unit from the sheet (or the unit you chose for it), and its price as the cost.
  2. Existing items keep their values. Only the fields you ticked are changed. Their unit is never changed.
  3. The stock quantities are filed as one opening stock count. They are not added to your stock yet. A different manager must approve that count in Stock Count first. Only then does the stock appear.
  4. Nothing is deleted, and recipes are not touched. Rows you left out are not created.
  5. The copy of your file on the server is deleted afterwards.
  • Prices are taken as written. VAT is not added or removed.
  • An item with stock but no price is created without a cost, and its stock is left out of the opening count. The page says "Add the cost later."
  • Who approves the count. A different manager must approve it while the rule Stock count: a second person must approve is on, which is the default. If an administrator has switched that rule off, the person who imported can approve the count. See Stopping stock going missing.

Confirm is turned off while any question still needs an answer. The page says "Some questions still need an answer." Answer them on Step 3, skip the row, or use Continue without them… on Step 4 (see Continuing without the blocked and unanswered rows). Confirm turns on when nothing is left to answer.

Importing the same file twice, cancelling, and clean-up

  • The same file again is blocked. The page says "This file was already imported on … by …". Only an administrator can import it again, by ticking Import again on the upload step.
  • Cancel. Click Cancel this import on Steps 2 to 4. The page says "Nothing has been saved to your stock, and the uploaded copy will be deleted." Confirm the cancel, and the page says "The import was cancelled and the uploaded copy deleted." A cancelled import teaches Import nothing.
  • Clean-up. The uploaded copy is kept on the server only while you work on it. It is deleted when you finish, when you cancel, or after 7 days.

Export your stock to Excel

You can download your current stock as an Excel file. It shows the stock as it is right now, including anything you imported and had approved. The download changes nothing.

Who can do it: anyone with the Import and Ingredients & Recipes permissions, the same two Import needs. Import must be switched on.

To download the whole stock:

  1. Open Admin menu → Stock → Import.
  2. Press Export current stock. A panel opens.
  3. Leave All tabs chosen (it is the default). To download some categories only, choose Only the tabs I tick below and tick them. Each one shows how many items it has.
  4. Press Download the stock workbook. The file downloads. Its name starts with Stock, then your hotel name and the date.

After a confirmed import, the result screen has Download the updated stock workbook. It downloads every tab.

What is in the file:

  • Dashboard (the first tab): the number of items out of stock, the reorder alerts, the expired batches and the stock value. It has links to each tab, and says how each figure is worked out.
  • One tab per category, in alphabetical order. Each tab starts with its category name.
  • Purchase Summary (the last tab): the estimated purchase cost for each tab, with a grand total.

Each category tab has these columns: Item Name, Batch, Balance, Unit, Expiry Date, Days to Expiry, Status, Action Required, Comments, Max Level, Purchase Qty (Max - Balance), Unit Price and Total Cost.

  • An item with batches gets one row for each batch, when its batches add up to its balance. Otherwise it gets one row with its total balance and the earliest expiry date.
  • Status uses the same tiers as the Batch Tracker: EXPIRED (past the expiry date), AT RISK (0 to 7 days left), CHECK SOON (8 to 30 days) or ACTIVE (more than 30 days).
  • Purchase Qty is Max Level minus Balance, never below zero. It is blank when the item has no Max Level. Total Cost is Purchase Qty times Unit Price, rounded to 2 decimals.
  • Purchase Qty and Total Cost show once for each item, on its first row, so nothing is counted twice.
  • Unit Price is the price as stored. VAT is not added or removed. A blank price means no price is set.
  • Total Cost is not the same as the Reorder / Buying page. That page also takes off stock already on order, and rounds up to whole packs.
  • Archived items are not listed.

Upload it back: you can upload the file in Import like any other list. It proposes no changes to your stock. Negative stock shows as a minus number, and Import will not accept a negative balance, so fix that stock first.

If something goes wrong: "Tick at least one tab to export, or choose "All tabs"." Tick a tab, or choose All tabs. "There is no stock to export yet." means no category has any items. "The stock workbook could not be built. Please try again." Try again, and tell an administrator if it keeps happening.

Very large lists and files that are too big

Import can read thousands of stock items. But the hotel's server sets how much memory and time one import may use, so a very large file can be too big to read in one go.

  • Size of the file. Step 1 shows Largest file. If your file is bigger, the page says "That file is bigger than this server accepts (…). Save a smaller copy and try again."
  • Too many rows. Import checks the rows before it reads them all. If the file will not fit, the import stops and the page says "This file has N rows - too many to read in one go on this server. Split it into files of about M rows (by sheet or category) and import them one after another." N and M are filled in for your file. The copy on the server is deleted, so upload each smaller file again.
  • A saved import that is too big to open. If an import you started earlier is now too big for the server to open, the page says "This import is too big for this server to open (…)." Cancel it, split the file, and import the parts.

How to split a big list.

  1. Split by sheet first. Save each sheet as its own Excel (.xlsx) file.
  2. If one sheet is still too big, split it by category. Copy a few categories into a new file. Keep the column headings at the top, and copy each category heading row with the items under it.
  3. Import each file on its own, one after another. Each file needs its own Confirm.

If something looks wrong

  • "Word and PDF files are not supported yet." Open the file in Excel, use Save As → Excel Workbook (.xlsx), and upload that.
  • "This is an old Excel file (.xls)." Save it again as an Excel Workbook (.xlsx), then upload that copy.
  • "That file is bigger than this server accepts." Save a smaller copy. You can remove old sheets you do not need.
  • "This file has N rows - too many to read in one go on this server." Split the file into the smaller files the message gives, by sheet or category. See Very large lists and files that are too big.
  • "This import is too big for this server to open (…)." Cancel it, split the file, and import the parts. See Very large lists and files that are too big.
  • "The file could not be read." Open the file in Excel to check it, save it again as .xlsx, and upload again.
  • "Your session has expired. Reload the page and try again." Reload the page and sign in again if asked.
  • "Row 12: Unit price in D12 is "abc", which is not a number. Fix it in the sheet and upload again, or skip this row." Fix the cell in your file and upload the file again, or skip that row on Step 3.
  • "… is negative. Negative amounts are not imported." Fix the cell in your file and upload again, or skip that row.
  • A row is Blocked and shows a reason with a cell, such as "Cell to fix in your file: C12". Fix that cell in your file and upload the file again. If you cannot fix it now, press Skip this row, or Continue without the blocked and unanswered rows… in Step 3. The row is listed in Step 4, and you can bring it back. See Blocked rows.
  • "Some questions about your sheets are still open" when you try to continue without rows. Press Go to step 2, answer the question about the sheet or column, then continue.
  • "The list changed since you looked at it, so nothing was skipped." Check the new count and try again.
  • A suggested unit is wrong. Do not press its Use button. Choose the right unit from the item's drop-down. Once you choose one, the drop-down says Change the unit…, and your choice is kept.
  • A value under Fixed for you is not what you want. Press Undo on that line in Step 4. The value goes back as written, and the page says "Put back as written. Anything that now needs an answer is asked in step 3." To bring the fix back, press Fix it again.
  • "This import is finished, and the copy of the file was deleted" when you try to download the skipped rows. The file was deleted when you confirmed. Ask an administrator, or import the rows again from the original file.
  • A sheet or column is missing from Step 2. Look at Columns not imported and the reason on the sheet's card.
  • A row says Needs answer and Confirm stays off. Answer the question on Step 3, or skip that row.
  • Stock did not change after Confirm. That is expected. The quantities wait in the opening count. Ask a different manager to approve it in Stock Count.
  • "This file was already imported on …" Ask an administrator, if the file really must come in again.
