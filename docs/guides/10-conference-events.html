Conference and Events

This guide covers conference room enquiries, hotel events, and event bookings at Rosalyns Beach Hotel. It explains what the guest sees on the website and what staff do in the admin area.

Who uses it
Receptionist, Conference Staff, Manager
Where to find it
Conference: Admin menu → Front Desk → Conference (/admin/conference-management.php)
Event bookings: Admin menu → Front Desk → Event Bookings (/admin/events-inquiries.php)
Events: Admin menu → Advanced → Events (/admin/events-management.php). The Advanced group starts folded, so click its heading to open it.
Permission needed
Conference Bookings to open the Conference page and handle enquiries.
Manage Conference Rooms to add, edit, delete or switch off rooms.
Conference Invoicing & Pricing to send invoices and quotations and change amounts.
Event Bookings to open the Event Bookings page and handle bookings.
Event Invoicing & Pricing to send invoices and quotations and change amounts on event bookings.
Events to open the Events page.
Only shown when
Conference: the Conference Rooms module is switched on in Settings → Modules. Events and Event Bookings: the Website & CMS module is switched on in Settings → Modules, and the Events Page switch is on in Settings → Modules.

What is on the screen

Conference page

  • Heading Conference Rooms Management with an Add New Room button.
  • One card per room showing the picture, name, description, the rate shown as MWK ... /day, how many guests it holds, its size in sqm, and a badge Active or Inactive. Each card has a power button (Deactivate room or Activate room), a bin button (Delete room) and an Edit Room button.
  • If a room has a display order above 0, a small number such as #2 shows on the card.
  • Below the cards, a table called Conference Enquiries with columns Reference, Company, Contact, Event Date, Time, Room, Attendees, Status, Amount, Actions. The newest event dates are at the top.
  • The Amount column shows the amount, or Pending when the amount is zero.
  • Buttons in the Actions column depend on the status: Confirm (pending only), Complete and Paid (confirmed only), Quote and Cancel (pending or confirmed), and Details (always).

Events page

  • Heading Events Management, a count such as 5 events total, and an Add New Event button.
  • A box called Upcoming Events Section Settings (see below).
  • One card per event, soonest date first. Badges on the card can be: Expired, Active or Inactive, Featured, Upcoming Section, Free or the ticket price, and Video. If the event has a capacity, the card shows seats taken, for example 12 / 40 seats, and · 3 waitlisted when guests are waiting.
  • Card buttons: Edit, Quote, Toggle, Featured, Upcoming, Delete.

Event Bookings page

  • Heading Event Bookings Management.
  • Filter tabs: All, Pending, Confirmed, Completed, Waitlisted, Cancelled, each with a count.
  • A search box (Search by name, email, phone, or reference...) with a Search button, and a Clear button once a search or filter is active.
  • A table with Reference, Name, Contact, Event, Attendees, Status, Created, Actions. The Status cell is a dropdown for open bookings. Actions are View and Delete.

You can also find any conference enquiry or event booking with the Search button at the top of the admin (or press Ctrl+K). Click a result to jump to that row.

What the guest sees: conference enquiry

Guests use the Conference page on the website (/conference.php). It lists every room that is switched on. If the Conference service is switched off, the guest sees "Our corporate booking service is temporarily unavailable" and is asked to contact the hotel directly.

  1. The guest clicks Send Inquiry on a room card. The window Conference Room Inquiry opens.
  2. They fill in: Company Name *, Contact Person *, Email *, Phone *, Event Date *, Start Time *, End Time *, Number of Attendees *. Optional: Event Type (Meeting, Conference, Workshop, Seminar, Training, Other), AV Equipment Requirements, Catering Required (tick box), Special Requirements.
  3. They tick I agree to be contacted about this enquiry request. The Submit Inquiry button stays greyed out until this is ticked.
  4. They click Submit Inquiry. They are taken to a page headed "Conference Enquiry Received" showing their reference (for example CONF-2026-04127). It says the events team will confirm availability within 24 hours.

The enquiry arrives on the Conference page as Pending. Its amount is set automatically to the room's full day rate. The guest and the hotel both get an email.

What the guest sees: event booking

Guests use the Events page on the website (/events.php). It lists active events. Events whose date has passed move to a Past Events section with an Expired ribbon, and cannot be booked. If the Events feature is off, the page sends the visitor to the home page.

  1. The guest clicks Book This Event on an upcoming event. (The Enquire button next to it opens the Contact Us page instead.) The window Book [event name] opens.
  2. They fill in Full Name *, Email *, Phone *, Guests (optional, 1 to 20, counts as 1 if left blank) and Message / Special Requests (optional).
  3. They tick I agree to be contacted about this booking request. The Send Booking Request button stays greyed out until this is ticked.
  4. They click Send Booking Request. They are taken to a confirmation page with a reference such as EVT-1A2B3C4D.
  • If seats are available (or the event has no capacity limit), the page says "Event Booking Received" and the booking is Pending. The guest gets a "received" email. Nothing is confirmed until staff confirm it.
  • If the event is full, the page says "You're on the Waitlist" and the booking is Waitlisted. The guest gets a waitlist email.

Problems show in a red box at the top of the form. The name, email, phone, message and consent rules are the same as the conference form above, with these differences:

MessageWhy
Full name: Name contains invalid charactersThe name has digits or symbols.
Guests: Value must be at most 20Guests must be between 1 and 20.
Message: Must be at most 1000 charactersThe message is too long.
This event is no longer taking bookings.The event was switched off, or its date has passed.
Too many submissions. Please wait a few minutes before trying again.Same limit as the conference form: 5 per visitor and 10 per internet connection in 10 minutes.

How to add a conference room

  1. Open Front Desk → Conference.
  2. Click Add New Room. The window Add New Conference Room opens.
  3. Under Room Information fill in Name * and Description *. Optionally choose a Featured Image (JPG, PNG or WebP).
  4. Under Room Details fill in Capacity * (a whole number, at least 1), Size (sqm) (optional), Full Day Rate * (0 or more, for example 350000) and Display Order (lowest shows first on the website, 0 if blank). In Amenities (comma separated) type for example Projector, Whiteboard, WiFi, Catering.
  5. Leave Active ticked if the room should show on the website now.
  6. Click Add Room. A green message "Conference room added successfully!" shows inside the window and the cards behind it refresh. Click Close.

If the image is not a JPG, PNG or WebP file, or is too large, the room is still saved but without a picture. Check that the card shows the picture.

How to edit, switch off or delete a conference room

Edit

  1. On the room's card click Edit Room. The window opens with the title Edit: [room name].
  2. Change the fields. The image field is called Replace Image. Leave it empty to keep the current picture.
  3. Click Save Changes. You will see "Conference room updated successfully!".

Switch a room off or on

  1. Click the power button on the card (tooltip Deactivate room or Activate room).
  2. The page reloads and the badge changes between Active and Inactive. An inactive room does not show on the website.

Delete

  1. Click the bin button on the card. A window asks "Delete conference room?" and "This permanently removes the room from conference management."
  2. Click Delete room (or Cancel to keep it).

A room that still has Pending or Confirmed enquiries cannot be deleted. A message window shows the reason and the room stays on the page. After a successful delete you see "Conference room deleted successfully!". Cancel or complete those enquiries first, or switch the room off instead of deleting it.

How to confirm a conference enquiry

  1. On the Conference page find the enquiry in the Conference Enquiries table. Click Details to read everything the guest entered: Reference, Company, Contact Person, Email, Phone, Event Date, Time, Conference Room, Number of Attendees, Event Type, Status, Catering Required, AV Equipment, Special Requirements, Total Amount, Notes.
  2. Click Confirm. A window asks "Confirm this conference enquiry?". Click Confirm.
  3. You will see "Conference enquiry confirmed successfully! Confirmation email sent." The guest receives the confirmation email. If the email could not be sent you will see "Conference enquiry confirmed successfully! (Email not sent: ...)" and the enquiry is still confirmed.
  • If the number of attendees is more than the room's capacity, the message adds "WARNING: 60 attendees exceed this room's capacity of 40 - confirm the layout with the client." The enquiry is still confirmed. Phone the client to agree the layout.
  • A copy of the confirmation is also emailed to the hotel's admin address when one is set up.

Two pending enquiries can ask for the same room at the same time. Only confirming commits the room. If another confirmed or completed enquiry already holds that room on that date with overlapping times, the system will not confirm (see the table at the end).

How to set the price and send a quotation

You need the permission Conference Invoicing & Pricing for this section.

Change the amount

  1. Click Details on the enquiry.
  2. In Update Total Amount: type the new amount (for example 450000).
  3. Click Update Amount. You will see "Total amount updated successfully!".

The amount starts as the room's full day rate. Change it here if you agreed a different price. You cannot change the amount of a cancelled enquiry.

Send a quotation

  1. On a Pending or Confirmed enquiry click Quote.
  2. A window asks "Send conference quotation now? This sends email and WhatsApp (if enabled)." Click Send quotation.
  3. You will see "Conference quotation sent to [guest email]." The guest gets a PDF quotation valid for 7 days. If WhatsApp is switched on and the guest's phone works you will also see "WhatsApp delivered."

The quotation uses the amount currently on the enquiry. Set the amount first, then send the quotation.

How to record payment and send the invoice

You need the permission Conference Invoicing & Pricing. The Paid button only shows on Confirmed enquiries.

  1. Check the amount is correct (see above). It must be more than zero.
  2. Click Paid. A window asks "Generate and send invoice for this conference?". Click Send invoice.
  3. The system records a cash payment for the amount still owed (the full amount including VAT if nothing was paid before, or only the remaining balance if part was already paid), issues a receipt, emails the receipt and invoice to the guest, and shows "Payment recorded successfully! Invoice sent to [guest email]".
  • If the account is already fully paid, nothing new is recorded and you see "Payment already recorded. Invoice resent to [guest email]".
  • The payment is always recorded as cash. For card, mobile money or part payments use the Payments screens (see the Finance guide).

How to complete or cancel a conference enquiry

Complete (after the event has taken place)

  1. On a Confirmed enquiry click Complete.
  2. A window asks "Mark this conference as completed?". Click Complete.
  3. You will see "Conference marked as completed!".

Cancel

  1. On a Pending or Confirmed enquiry click Cancel.
  2. A window asks "Cancel this conference enquiry?". Click Cancel enquiry (or Keep enquiry to leave it).
  3. You will see "Conference enquiry cancelled successfully! Cancellation email sent." The guest is emailed, and the cancellation is logged.

Cancelling voids the bill (amount due becomes zero). Money the guest already paid is not lost: it stays on the account as credit owed back. You will see a line such as "MWK 100,000.00 already paid stays as credit owed back - refund it from the payment Refund screen." Refund it from the payment's Refund screen or issue a credit note. If your hotel's cancellation refund setting is to refund everything paid, the refund is made for you at the moment of cancelling. A cancelled enquiry cannot be re-opened.

Keep notes

  1. Click Details.
  2. Type in Update Notes: and click Update Notes. You will see "Notes updated successfully!". Notes are internal; the guest never sees them.

How to add or edit an event

  1. Open Advanced → Events.
  2. Click Add New Event. To change an existing event click Edit on its card.
  3. Fill in: Event Title *, Description *, Event Date *, Start Time, End Time, Location (for example Grand Conference Hall), Ticket Price (MWK) (enter 0 for a free event), Capacity and Display Order.
  4. Capacity is the number of seats. Leave it blank or enter 0 for unlimited. When the seats are used up, new guests go on the waitlist.
  5. Optionally add an Event Image (JPG, PNG or WebP). For Event Video (Optional), paste a YouTube, Vimeo, Dailymotion or direct video link, or upload a video file. When editing an event that has a video, Remove Video takes it off.
  6. Tick the boxes you want: Feature this event, Show in Upcoming Events section (homepage), Active (visible on website). Active is ticked by default.
  7. Click Save. You will see "Event added successfully!" or "Event updated successfully!" inside the window, and the cards refresh. Click Close.

After you save a new event, the window stays open and turns into an edit window for that event. Click Save again only if you make more changes. Clicking Save twice does not create two events.

How to switch an event on or off, feature it, or delete it

  • Toggle switches the event between Active (shows on the website) and Inactive (hidden). Use it instead of deleting when you may need the event again.
  • Featured adds or removes the Featured badge.
  • Upcoming adds or removes the event from the Upcoming Events section.
  • Delete asks "Delete this event?". Click OK to delete.

Each of these reloads the page.

An event that still has Pending, Confirmed or Waitlisted bookings cannot be deleted. A window titled Action Failed shows the reason and the event stays on the page. After a successful delete a window titled Success shows "Event deleted successfully!". Cancel those bookings first on the Event Bookings page, or use Toggle to switch the event off instead.

How to set up the Upcoming Events section

This is a block of event cards that can appear on other website pages.

  1. On the Events page find the box Upcoming Events Section Settings.
  2. Tick or untick Enable Upcoming Events section on public pages.
  3. Choose Max Events to Display (1 to 8).
  4. Under Show on Pages tick where it should appear: Homepage, Rooms Showcase, Restaurant, Conference, Gym.
  5. Click Save Settings. You will see "Upcoming events section settings saved!".
  6. Use the Upcoming button on each event card to choose which events appear. Only active events with a future date that are marked this way are shown.

How to send an event quotation

This sends a quotation for an event to anyone, without needing a booking first.

  1. On the event's card click Quote. The window Send Event Quotation opens. The Event field is filled in.
  2. Fill in Recipient Name *, Recipient Email *, optionally Recipient Phone (for WhatsApp) (for example +265...), Attendee Count * (at least 1) and Valid For (days) (1 to 30, 7 by default).
  3. Edit Quotation Notes if you wish. It starts with a line naming the event and its date.
  4. Leave Also send via WhatsApp (when phone is provided and WhatsApp is enabled) ticked or untick it.
  5. Click Send Quotation. You will see "Event quotation sent to [email]." and, if it worked, "WhatsApp delivered."

How to handle event bookings

  1. Open Front Desk → Event Bookings. Use the filter tabs or the search box to find the booking.
  2. Click View. The window Event Booking Details shows Reference Number, Full Name, Email, Phone, Event, Event Date, Number of Attendees, Status, Consent Given, Created At, the guest's Message, and an Accounting block with Total Amount, Amount Paid, Amount Due and Payment Status.
  3. To confirm: click Confirm and answer OK to "Confirm this event booking?". You will see "Event booking confirmed successfully! Confirmation email sent."
  4. After the event: click Mark Completed and answer OK to "Mark this booking as completed?". You will see "Event booking marked as completed!"
  5. To keep a private note, type in the Internal notes... box and click Save Notes. You will see "Notes updated successfully!"

You can also change a booking between Pending, Confirmed and Completed with the dropdown in the Status column. It saves as soon as you pick a value and shows "Event booking status updated successfully!". Cancelled and waitlisted bookings show the status as plain text, with no dropdown.

Delete a booking

Click Delete in the row and answer OK to "Are you sure you want to delete this booking?". You will see "Event booking deleted successfully!". Only use this for mistakes or test entries. If the guest changed their mind, cancel the booking instead.

How to move a guest off the waitlist

  1. Seats must be free. Either another booking was cancelled, or you raised the event's Capacity on the Events page.
  2. On the Event Bookings page click the Waitlisted tab, then View on the booking.
  3. Click Promote from waitlist. A window asks "Move this booking off the waitlist? The guest will be emailed that a place is available." Click OK.
  4. You will see "Booking moved off the waitlist (now pending). The guest has been emailed." The booking is now Pending. Confirm it as usual.

When you cancel a booking and other guests are waiting, the message ends with "[number] booking(s) are on the waitlist for this event - promote one from the Waitlisted tab."

How to price, invoice and cancel an event booking

The price, invoice and quotation controls only appear in the booking window for staff with the permission Event Invoicing & Pricing. Cancel and Confirm do not need it.

Set the amount

  1. Click View on the booking.
  2. In Set Total Amount: type the amount, for example 25000, and click Save Amount. You will see "Total amount updated successfully!".

A booking made on the website starts with no amount. Set the amount before sending an invoice.

Send a quotation for the booking

  1. In the booking window enter the number of days it stays valid (7 by default) in the small box and click Send Quotation.
  2. You will see "Event booking quotation sent to [email]." and "WhatsApp delivered." when that worked.

Record payment and send the invoice

  1. Click Record Payment & Send Invoice. It is greyed out ("Set a total amount first") until the amount is above zero.
  2. The system records a cash payment for the amount still owed, issues a receipt and emails the invoice. You will see "Payment recorded successfully! Invoice sent to [email]". If the booking is already fully paid you see "Payment already recorded. Invoice resent to [email]".

Cancel a booking

  1. Click Cancel Booking in the booking window. The window says "Cancel this booking? The bill is voided; any payment already recorded stays as credit owed back to the guest (refund it from the Payments screen)." Click OK.
  2. You will see "Event booking cancelled successfully! Cancellation email sent." The guest is emailed. Any money already paid stays as credit owed back, so refund it from the payment's Refund screen or with a credit note. A cancelled booking cannot be re-opened: ask the guest to book again.

Rules the system enforces

  • A conference enquiry can only be confirmed while it is Pending, completed while it is Confirmed, and cancelled once. Event bookings follow the same rules.
  • If a deposit is required and has not been fully paid, the booking cannot be confirmed or completed. This also applies to the status dropdown on Event Bookings.
  • A conference room cannot be confirmed for a date and time when another confirmed or completed enquiry already holds the same room with overlapping times. If the enquiry has no times, any confirmed booking that day blocks it.
  • A conference room with pending or confirmed enquiries cannot be deleted. An event with pending, confirmed or waitlisted bookings cannot be deleted.
  • Event seats: pending, confirmed and completed bookings use up seats, counting every guest. Waitlisted and cancelled bookings do not. A guest whose party does not fit goes on the waitlist automatically.
  • Past events and inactive events cannot be booked on the website.
  • A booking with payments recorded cannot be deleted from Event Bookings. Cancel it.
  • Cancelling voids the bill but never removes payments. Paid money is shown as credit owed back until it is refunded.
  • Prices, invoices and quotations need the Invoicing & Pricing permission. Without it, the buttons are missing from the event booking window. On the Conference page the buttons are still visible, but pressing them shows "Error: You do not have permission to handle conference invoicing or pricing."
  • On the Conference page, adding, editing, switching off or deleting rooms needs Manage Conference Rooms. Without it you see "You do not have permission to manage conference room facilities."
  • Conference and event images must be JPG, PNG or WebP.
