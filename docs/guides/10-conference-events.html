Conference Rooms

Manage conference venues that guests can browse and enquire about on your public website.

Adding a conference room

  1. Go to Admin → Conference Management (/admin/conference-management.php).
  2. Click Add Conference Room.
  3. Fill in: room name, description, capacity (number of people), size in square metres, and daily rate.
  4. Add amenities one by one (projector, whiteboard, AV system, catering, etc.).
  5. Upload a cover photo — the system accepts JPG, PNG, and WebP only and validates the file type twice (extension + MIME check) before saving to images/conference/.
  6. The image is automatically added to the unified media library for centralised management.
  7. Save. The room appears immediately on /conference.php.

Public inquiry workflow

  1. A guest visits /conference.php, browses the rooms, and submits an inquiry (company name, contact person, preferred date, duration, attendee count, special requirements).
  2. The system validates the form server-side (CSRF protected) and emails a confirmation to the guest.
  3. The manager reviews the inquiry in the admin Conference Management inbox and follows up directly.
  4. When the client commits, the manager Confirms the inquiry — this is the point the room is actually held.
Double-booking is now blocked at confirmation. If the same conference room is already confirmed for that date with an overlapping time, the system refuses the confirmation and names the clashing reference. Two pending inquiries for the same slot can still coexist — only confirmation commits the room, so confirm the one you intend to honour.

Payments & balances

Record conference payments from the Add Payment screen or the inquiry itself. However you collect them, the balance is calculated the same way as rooms, gym and events: the amount due is measured against the VAT-inclusive (gross) invoice total, and the invoiced total is locked at the rate it was raised at.

Conference room pricing is shown publicly as a daily rate. Any discounts for multi-day bookings should be negotiated manually and recorded as a custom booking charge.

Hotel Events

Keep the public events page fresh — upcoming events build anticipation; past events build credibility.

Publishing an event

  1. Go to Admin → Events Management (/admin/events-management.php).
  2. Click Add Event. Fill in: title, description, event date, and optionally a price or ticket link.
  3. Upload a cover image (JPG / PNG / WebP) — MIME-validated before storage.
  4. Optionally upload a video via the async video handler. The video path is stored alongside the image and both sync to the media library.
  5. Set Active to publish immediately, or leave inactive to schedule for later.
  6. Save. The event appears on /events.php.

How the public page works

  • Upcoming — events with a future date, sorted nearest first.
  • Past — events with a date in the past, sorted most-recent first.
  • The page updates automatically at midnight — no action needed to move events between sections.
  • Both image and video display if provided. Videos play inline without leaving the page.

Editing & removing events

  • Click Edit on any event card to update any field.
  • Toggle Active off to hide an event without deleting it.
  • Delete removes the event and its media record from the library.

Gym & Fitness Centre

The gym is a full DB-driven experience — content, classes, packages, and a membership conversion pipeline.

Managing the gym page content

All gym content is edited in the database via the admin system. Tables you control:

What Table Appears on
Hero text & tagline gym_content Top of /gym.php
Facility features gym_features Features grid
Equipment & zones gym_facilities Facility cards
Group & personal class schedule gym_classes Class schedule table
Membership tiers & prices gym_packages Pricing cards

Managing gym inquiries

When a visitor submits a membership inquiry on /gym.php, it lands in Admin → Gym Inquiries (/admin/gym-inquiries.php).

  1. Open the New tab to see unactioned inquiries. Each card shows name, email, phone, and membership type.
  2. Click Mark Contacted — status moves to Contacted and the system sends a notification email to the staff member responsible.
  3. Once the member has enrolled, click Mark Converted — status moves to Converted and a welcome email is sent to the new member automatically.
Status Meaning Email triggered
new Inquiry just submitted, awaiting action None
contacted Staff has reached out to the prospect Staff notification
converted Prospect enrolled as a member Member welcome email

Search & filter

  • Use the tab strip to filter by status (New / Contacted / Converted / All).
  • Use the search box to find by name, email, phone, or reference number.
  • Delete an inquiry with the Delete button — a confirmation modal prevents accidents.
Never delete a converted inquiry — it is your enrolment record. Use the status tabs to archive instead.
