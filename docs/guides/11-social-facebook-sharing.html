Facebook and WhatsApp

How to connect the Rosalyns Beach Hotel Facebook Page so staff can post rooms, events, conference rooms, gym packages and menu items from the admin, and how to set up WhatsApp notifications.

Who uses it
An administrator sets it up. Staff with access to rooms, events, conference, gym or menu then post.
Where to find it
Admin menu → Advanced → Facebook Settings (/admin/facebook-settings.php) and WhatsApp Settings (/admin/whatsapp-settings.php)
Permission needed
Facebook Settings and WhatsApp Settings. To post: the permission for the page you post from (Rooms, Events, Conference, Gym or Menu).
Only shown when
The pages that carry the share buttons follow their own modules: Rooms and Conference Rooms need Bookings and Conference switched on; Events needs the Events page; Gym needs Gym. The two settings pages need Website & CMS switched on in Settings → Modules.

How to connect the Facebook Page

  1. Open Advanced → Facebook Settings.
  2. Paste the Page Access Token. Follow the on-screen Token Setup Guide (Graph API Explorer, permissions pages_manage_posts, pages_read_engagement and pages_show_list). A saved token is never shown again; to keep it, leave the box blank.
  3. Click Save Facebook Settings once so the token is stored.
  4. Click Fetch from Token. If your token covers several Pages, pick the right one. The Page ID and name fill in.
  5. Tick Enable Facebook Page Posting.
  6. Set Default Hashtags. Each one must start with # and be separated by spaces, for example #hotel #malawi. They are added to the end of every post and can be changed before posting.
  7. Tick the areas where you want share buttons.
  8. Click Save Facebook Settings. You will see "Facebook settings saved successfully."

If posting is switched off, every Post to Facebook button disappears from the admin. The Page ID must be numbers only. The Page ID and token are needed before posting can be switched on.

How to send a test post

  1. Save a token first. Until then the test button and Fetch from Token are greyed out.
  2. Type a message, or leave it blank for a standard test line.
  3. Click Send Test Post to Facebook Page.
  4. You will see Success! with a View post on Facebook link, or Failed. with the reason.

The test publishes a real post on your Page. Delete it on Facebook afterwards if you do not want it to stay.

How to post one item to Facebook

The button appears on these pages when posting is enabled, a token is saved, and the matching share tick is on:

  • Rooms: Settings → Rooms, the Facebook button on each room card (tooltip Preview & post this room to your Facebook Page).
  • Events: Advanced → Events, the Facebook button on each event.
  • Conference: Front Desk → Conference, the Facebook button on each room card.
  • Gym packages: Advanced → Gym Packages (Share on Facebook).
  • Menu items: the Feature button on each item in the menu page.
  1. Click the Facebook button. A window opens: Compose post on the left, a Post preview on the right.
  2. Read the caption. It is written for you from the item's details and your hashtags. Edit it as you like. A character count sits under it.
  3. Tick or untick Include room image in post (the wording changes for events, conferences and menu items).
  4. Click Post to Facebook Page.
  5. You will see "Posted to Facebook!" with a link to the post. If the caption is empty you will see "Please enter a caption."

How to post several items together

  1. On the Rooms page click Compose & Preview Post in the banner Share All Rooms on Facebook. Conference has the same banner for conference rooms. Gym has Share All Packages. The menu page has Share Full Menu.
  2. Tick the items to include. Use the select-all and clear buttons if you want.
  3. Edit the caption and the image option, check the preview, then click the post button.

How to set up WhatsApp

The WhatsApp Settings page sends booking messages through Meta's WhatsApp Business service. The same hotel number is used for the End of Day WhatsApp summary.

  1. Open Advanced → WhatsApp Settings.
  2. In API Configuration fill in Hotel WhatsApp Number (with country code, like +265888123456), WhatsApp Phone Number ID, WhatsApp Business Account ID (both numbers from Meta) and Permanent Access Token.
  3. Under Notification Triggers tick the events to message about: New Booking Created, Booking Confirmed, Booking Cancelled, Guest Check-in, Guest Check-out.
  4. Under Notification Recipients choose Send to Guest (uses the phone number on the booking) and Send to Hotel/Admin. Enter the staff numbers in Admin WhatsApp Numbers, separated by commas.
  5. Under Message Template Names type the names of your approved Meta templates for Booking Confirmed Template and Booking Cancelled Template. They must match Meta exactly. Letters, digits and underscores only. Blank gives booking_confirmed and booking_cancelled.
  6. Tick Enable WhatsApp Notifications and click Save Settings. You will see "WhatsApp settings saved successfully!"
  7. To check it works, enter a number under Test WhatsApp Integration and click Send Test Message. Confirm the prompt. The result shows as Test Result at the top.

A test sends a live message and may be charged by Meta or WhatsApp.

Rules the system enforces

  • Posting needs the right permission for the thing you post: Rooms, Events, Conference, Gym or Menu.
  • You can post only active rooms and events.
  • Each area can be turned off with its share tick on Facebook Settings. A gym toggle does not exist on that page; gym sharing follows the main switch.
  • WhatsApp cannot be enabled without the access token and phone number ID.
