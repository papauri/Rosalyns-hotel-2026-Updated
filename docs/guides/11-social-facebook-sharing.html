Social Media & Facebook Sharing

How to connect your Facebook Page, publish from admin, and keep posts accurate, safe, and consistent.

Audience Manager & marketing team Read time 8 min Main page /admin/facebook-settings.php

1. What this feature does

  • Lets you publish content to the hotel Facebook Page directly from admin.
  • Supports sharing content from Rooms, Events, Conference, and Menu areas.
  • Allows default hashtags to be appended automatically.
  • Includes a test-post tool so you can validate the setup before daily use.

2. Prerequisites

Requirement Why it matters
Facebook Page admin/editor access You need permission to post to the Page.
Facebook app token with page permissions Without a valid token, posts cannot be sent.
Page ID configured in admin The system needs to know which Page receives posts.
Stable internet Publishing uses Facebook Graph API in real time.

3. First-time setup

  1. Open /admin/facebook-settings.php.
  2. Turn on Enable Facebook Page Posting.
  3. Paste the Page Access Token and save.
  4. Click Fetch from Token to auto-fill Page ID and Page Name.
  5. Set Default Hashtags (for example: #RosalynsHotel #Mangochi).
  6. Choose which sections can show share buttons (Rooms, Events, Conference, Menu).
  7. Click Save Facebook Settings.
Keep your token private and rotate it whenever the Facebook app security policy changes.

4. Validate with a test post

  1. In the same settings page, go to Test Post.
  2. Enter a short message like Test post from Rosalyns admin.
  3. Click Send Test Post to Facebook Page.
  4. Confirm success and open the returned Facebook link.
  5. Delete the test post from Facebook if it is only for setup verification.
Test Post publishes a real post to your live Facebook Page.

5. Daily publishing workflow

Step Action
1 Open content in admin (room, event, conference item, or menu item).
2 Click the Facebook share action when available.
3 Review generated caption; keep it short, clear, and specific.
4 Confirm media and key details (price, date, phone, booking link).
5 Publish and verify immediately on the Facebook Page.

6. Caption quality checklist

  • Lead with one strong message in the first line.
  • Include a clear call-to-action: book now, call, or WhatsApp.
  • Keep hashtags relevant and limited (3 to 6 is usually enough).
  • Never publish placeholder text like lorem ipsum or test amounts.
  • Match currency format to MWK where pricing is shown.

7. Troubleshooting

Issue Fix
Share button not visible Enable posting globally and enable the specific section toggle in Facebook Settings.
"Invalid token" or permission error Generate a new token with pages_manage_posts, pages_read_engagement, and pages_show_list.
No pages returned by Fetch from Token Confirm the token belongs to a user/system user with access to the hotel Page.
Post succeeded but content is wrong Correct the source content in admin and re-post with a revised caption.

8. Governance and safety

  • Limit publishing rights to manager-level users.
  • Log all post attempts for audit (keep post logging enabled).
  • Review posts daily for brand consistency and factual accuracy.
  • Use official contact details only: hotel phone, WhatsApp, and booking URL.
