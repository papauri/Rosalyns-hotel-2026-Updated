Guide 05 · In-room service

Room Service

The control panel for in-room food, drink and service requests. Charges go directly to the guest folio.

URL /admin/room-service-dashboard.php Role room_service · receptionist · manager · admin Read time 5 min

At-a-glance KPIs

Card Meaning
Active orders Orders not yet delivered to a room.
Delivered today Completed today (resets at midnight).
Avg. delivery time From order placement to mark delivered.
Revenue today Sum of room-service charges added to folios today.

Place a new order

  1. Click + Place Room-Service Order.
  2. Search the room number or guest name — current in-house bookings autocomplete.
  3. Pick items from the menu (grouped by station — kitchen / bar / coffee).
  4. Enter qty for each line.
  5. (Optional) Add a special note (e.g. "no ice", "extra towels").
  6. Tap Send to kitchen & charge to folio.
The order fires to the right station (KDS / BDS / CDS); a line is added to the guest's booking folio with VAT applied. Stock is deducted when the station marks each item Ready — not at order placement. The folio charge posts immediately at placement for billing accuracy.

Mark an order delivered

  1. From the Active queue, tap Mark Delivered on the order card.
  2. The card moves to Delivered today and the runner timestamp is recorded.

Voiding admin / manager only

  1. Open the order from Stock Orders → Room Service.
  2. Tap Void, type a reason ≥ 8 characters.
  3. Stock is restored for any items already marked Ready on the station display, the folio line is reversed, and the order disappears from KDS/BDS/CDS.

Tips

  • Always confirm the room number with the guest before placing — folios cannot be moved between bookings.
  • If a guest checks out before paying, the room-service line stays on the unpaid folio and shows on the final invoice.
  • For complimentary orders, admin or manager can void the line after delivery, which clears the folio charge but keeps the stock deducted (use this for staff meals / comps).
