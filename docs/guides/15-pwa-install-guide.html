PWA & Service Worker

Install the hotel system as an app on any device — phone, tablet, or laptop — and keep it running smoothly offline.

URL /admin/cache-management.php Role admin Read time 5 min

What is a PWA?

PWA stands for Progressive Web App. It lets you install the Rosalyn's website (guest-facing) or the Admin Panel directly onto any device — like a real app — without going through the App Store or Google Play.

Once installed:

  • It opens in its own window, no browser address bar in the way.
  • It loads instantly because common files (CSS, JS, images) are saved on the device.
  • It works even when internet is slow or cut (load-shedding friendly).
  • Staff can pin POS, KDS, and BDS to the tablet home screen.

What is a Service Worker?

A service worker is a tiny background script the browser downloads once and keeps running silently. Think of it as a smart cache assistant that:

It doesWhy it helps
Saves CSS, JS, and fonts on the device Pages load in under a second even on slow 3G
Serves a friendly offline page when there's no internet Guests don't see a blank browser error
Keeps the admin POS/KDS working during brief network drops Orders aren't lost during load-shedding cut-overs

There are two separate service workers in use:
• Public SW — covers the guest-facing website (/public-sw.js).
• Admin SW — covers the admin panel, POS, KDS, BDS (/admin/sw.js).

Installing the App on a Device

Android phone / tablet (Chrome)

  1. Open Chrome and go to the site (or admin panel).
  2. A banner will appear at the bottom: "Install Rosalyn's Hotel". Tap Install.
  3. If you missed the banner: tap the three-dot menu (⋮) → Add to Home Screen.
  4. The icon appears on the home screen. Tap it — it opens as a full-screen app.

iPhone / iPad (Safari)

  1. Open Safari (must be Safari — Chrome on iOS cannot install PWAs).
  2. Go to the site or admin panel.
  3. Tap the Share button (the square with an arrow pointing up).
  4. Scroll down and tap Add to Home Screen.
  5. Give it a name and tap Add.

Windows laptop / desktop (Chrome or Edge)

  1. Open Chrome or Edge and go to the site.
  2. Look for the install icon (⊕) in the address bar on the right side.
  3. Click it and choose Install.
  4. The app opens in its own window and appears in the Start Menu.

Tip for POS/KDS tablets: Install the Admin App on every tablet used in the restaurant, bar, and kitchen. This means even if the Wi-Fi drops briefly, orders on-screen stay visible.

Bumping the SW Version (Cache Refresh)

Occasionally, after a big update to the site's design or code, you want all devices — including those with the PWA installed — to throw away their old cached files and download the latest. That is what Bumping the SW Version does.

When should I bump the version?

SituationBump needed?
New CSS or JS deployed (site redesign, big feature) ✅ Yes
New images or logos uploaded ✅ Yes
Minor text edits, DB changes, settings updates ❌ No
PHP page changes only (no new CSS/JS) ❌ No
After a MSP developer deployment ✅ Yes — developer will tell you

How to bump the version

  1. Go to Admin → Cache Management (/admin/cache-management.php).
  2. Scroll down to the PWA Service Worker section.
  3. You will see the current version codes for both the Public SW and Admin SW (e.g. rh-public-v1-2026-05-22).
  4. Click Bump SW Version Now.
  5. Confirm the dialog. Done.

The date in both version strings is now updated to today. The next time any device loads the site, the browser notices the version changed and automatically discards the old cache and downloads fresh files. Devices with the PWA installed will update silently in the background.

Note: You do not need to do this regularly. Bumping too often is harmless but forces every visitor to re-download all cached files, which uses more data. Only bump when actually needed.

Reading the Version String

The version string looks like this:

rh-public-v1-2026-05-22
PartMeaning
rhRosalyn's Hotel
public / adminWhich app the SW covers
v1Major version (only changed by MSP developers)
2026-05-22Date of last bump — this is the part that changes when you click the button

The Offline Page

If a guest visits the website while their device has no internet connection, they will see a friendly offline page (/offline.php) instead of a browser error. It displays the hotel branding and a "Try Again" button. No action is needed from your side — this is automatic.

The admin panel has its own offline handling built into the service worker for POS and KDS screens.

Troubleshooting

ProblemFix
The install banner didn't appear You may have already dismissed it. On Android, use ⋮ → Add to Home Screen. On iPhone, use Safari Share → Add to Home Screen.
I can see old CSS/JS after a deployment Bump the SW version from Cache Management. Then on the affected device, close the app and reopen it.
POS is showing a stale menu after updating prices Menu/price data is never cached by the SW — do a normal browser refresh (pull-down to refresh on mobile, or Ctrl+R on desktop).
A device is stuck on an old version even after bumping On the device, go to Settings → Apps → find Chrome/Safari → Clear Cache. Then reopen the site.
The install icon doesn't appear on desktop Make sure you are using Chrome or Edge (not Firefox). The site must be served over HTTPS.
