Installing the admin as an app

You can install the Rosalyns Beach Hotel admin on a phone, tablet or computer so it opens in its own window, without the browser address bar and tabs. This is most useful for the POS till and the kitchen, bar and coffee screens.

Who uses it
Anyone who signs in to the admin on a till, tablet, phone or office computer.
Where to find it
You install it from your browser. The hotel can change how often the install banner comes back in Admin menu → Settings → Hotel Settings → PWA Install Banner.
Permission needed
Installing needs none. Changing the banner setting needs Hotel Settings.

What installing does

  • The app is called <hotel name> Admin (for example Rosalyns Beach Hotel Admin). The name under the icon on your home screen is the hotel's short name, set in Hotel Settings → Hotel details & policies → Short name (app icon / home screen). The icon is the hotel logo.
  • It opens full screen. There is no browser address bar.
  • It opens on the POS Till page. If you are not signed in yet, you sign in first as normal.
  • The app covers the whole admin, not only the till. You reach every page you have permission for, the same as in a browser.
  • On devices that support it, pressing and holding the app icon offers four shortcuts: POS Till, Receive Stock, Kitchen Display and Dashboard.
  • Installing does not change your sign-in, your permissions or any data. You can remove the app at any time, the same way you remove any other app.

The Install Admin App banner

In browsers that offer installing to web pages (Chrome and Edge), the admin shows a small dark box called Install Admin App with the text "Run POS & KDS without a browser tab." It has these controls:

ControlWhat it does
InstallOpens your browser's own install question. Confirm it there to install. The box then goes away.
Minus button (Minimise)Shrinks the box to just its icon and two buttons. Click the plus button (Expand) to open it again.
Cross button (Dismiss)Hides the box and starts a waiting period. The box does not come back until the waiting period is over (see below). The default is 14 days.
DragYou can drag the box by any part that is not a button, to move it out of the way.
  • On a computer or tablet the box sits at the top right. On a small phone screen (480 pixels wide or less) it sits near the bottom right.
  • The box is never shown on the POS Till or the kitchen, bar, coffee and room service station screens, because it would cover their buttons. It appears on the Dashboard and the other admin pages. Install from there.
  • If you click Install and then cancel your browser's own question, the box goes away but the waiting period does not start, so it comes back on the next page you open.
  • The waiting period is remembered separately in each browser on each device. Dismissing it on the till does not hide it on the manager's laptop.
  • If you do not see the banner, you can still install with the steps below.

How to install on Android (Chrome)

  1. Open Chrome and go to the admin address, then sign in.
  2. If the Install Admin App banner appears, tap Install, then confirm in the box Chrome shows. Skip to step 5.
  3. If it does not appear, tap the three-dot menu at the top right of Chrome.
  4. Tap Install app (some versions say Add to Home screen), then confirm.
  5. Find the Rosalyns Beach Hotel icon on your home screen or in your app list. Tap it to open the admin as an app.

Use Chrome. Other Android browsers may not offer the install question. Tablets used as a till or kitchen screen are best installed once, then opened from the icon.

How to install on iPhone or iPad (Safari)

Safari on iPhone and iPad does not show the Install Admin App banner. You add the admin to the Home Screen by hand.

  1. Open Safari (not Chrome) and go to the admin address, then sign in.
  2. Tap the Share button (a square with an arrow pointing up).
  3. Scroll down and tap Add to Home Screen.
  4. Check the name, then tap Add.
  5. Tap the new icon on your Home Screen to open the admin as an app.

The wording of the Safari menus can change a little between iOS versions. If you cannot find Add to Home Screen, scroll further down the Share menu.

How to install on Windows or Mac (Chrome or Edge)

  1. Open Chrome or Edge and go to the admin address, then sign in.
  2. If the Install Admin App banner appears, click Install, then confirm in the box the browser shows. Skip to step 5.
  3. If it does not appear, look at the right-hand end of the address bar for an install icon (a small screen with a down arrow) and click it. Or open the browser's three-dot menu and look for an entry with the word Install in it.
  4. Confirm the install.
  5. The admin opens in its own window. On Windows, it is added to the Start menu. You can pin it to the taskbar.

The exact menu wording depends on the browser version. Look for the word Install.

How to change how often the banner returns

This is the number of days the banner stays hidden after a staff member dismisses it.

  1. Open Admin menu → Settings → Hotel Settings, then go to the card PWA Install Banner (near the bottom). The PWA link in the Jump to bar at the top takes you there.
  2. In Re-show banner after dismissal (days), type a whole number from 1 to 365. The default is 14. A 1 shows it every day. A 365 hides it for almost a year.
  3. Click Save PWA Settings. You will see "PWA install banner settings saved — staff will be prompted every N day(s) after dismissing."

Staff see the new number the next time they load an admin page. A banner that was already dismissed starts counting from the day it was dismissed, using the new number.

What happens with no internet

  • The Online pill in the top bar turns red and says Offline when the connection drops. It turns amber and says Syncing N... while saved actions are being sent.
  • Pages you opened recently may still open from the device's memory. A page that was never opened shows "You're offline" with "This page is not available offline."
  • On screens that support it (the POS), actions you take while offline are kept on the device and sent to the server automatically when the connection returns. A dark bar at the bottom of the screen says "Offline — queued", then "Back online — syncing", with a count of queued actions and a Retry now button.
  • Screens, styles and code are always loaded fresh from the server when you are online, so an installed app is never stuck on an old version.
  • Offline sales appear in Admin menu → Restaurant & Bar → Offline Log (permission Offline Activity Log).

Rules the system enforces

  • The install banner never covers the POS Till or the station screens.
  • The banner is hidden for the number of days set in Re-show banner after dismissal (days). That number must be between 1 and 365.
  • Sign-in and permissions work exactly as in a browser. Installing never gives extra access.
